# 채팅 패널을 학습자로 사용

채팅 패널을 사용하여 Live Hub 세션 중 대화에 참여합니다. 모든 참가자에게 메시지를 보내고, 질문을 하고, 채팅 메시지를 관리할 수 있습니다. 강사가 개인 메시지를 활성화한 경우 다른 참가자와 직접 채팅할 수도 있습니다. 이 문서에서는 학습자가 사용할 수 있는 채팅 기능에 대해 설명합니다.

## 채팅 패널에 액세스

학습자는 채팅 패널을 사용하여 토론에 참여하고 질문을 하며 세션 중에 다른 사람들과 연결할 수 있습니다.

채팅 패널에 액세스하려면 다음 단계를 따르십시오.

1. Live Hub 세션에 참여합니다.

1. 컨트롤 막대에서 ![open-chat-panel](./assets/open-chat.svg)을 선택합니다. 기본적으로 채팅 패널이 **모두** 탭과 함께 열리므로 진행 중인 대화에 참여하거나 팔로우할 수 있습니다.

1. 다음 탭 중 하나를 선택합니다.

   1. 모두

   1. 비공개

   ![채팅 패널 탭](assets/chat-panel-tabs.png)
   *모든 사용자 및 비공개 탭이 표시된 채팅 패널*

1. 메시지를 입력하고 **보내기**&#x200B;를 선택합니다.

## 채팅 패널 사용자 정의

채팅 패널을 사용자 정의하여 Live Hub 세션 중에 알림을 관리하고 메시지 가독성을 높일 수 있습니다.

채팅 패널을 사용자 정의하려면 다음과 같이 하십시오.

1. **채팅** 패널을 엽니다.

1. 채팅 패널의 오른쪽 상단에서 **기타 옵션(⋯)**&#x200B;을 선택합니다.

1. 다음 옵션 중 하나를 선택합니다.

   1. **알림 끄기**: 현재 세션에 대한 채팅 알림을 사용하지 않도록 설정합니다.

   1. **텍스트 크기 변경**: 쉽게 읽을 수 있도록 채팅 메시지의 크기를 늘리거나 줄입니다.

   ![채팅 패널 설정](assets/chat-panel-settings.png)
   *알림을 끄고 채팅 메시지의 텍스트 크기를 조정하는 옵션을 표시하는 채팅 패널 설정*

## 채팅 메시지 관리

메시지와 상호 작용하여 대화를 최신 상태로 유지할 수 있습니다. 메시지에 회신하거나, 이모지에 반응하거나, 메시지를 보낸 후 편집하거나, 더 이상 필요하지 않을 때 삭제합니다.

채팅에서 메시지를 관리하려면:

1. 메시지 위에 마우스를 가져가면 사용 가능한 작업을 볼 수 있습니다.

1. 필요한 작업을 선택합니다.

| **작업** | **설명** |
|----|----|
| **반응** | 새 채팅 메시지를 보내지 않고 메시지를 승인하거나 응답할 수 있도록 이모지 반응을 추가합니다. |
| **회신** | 특정 메시지에 응답합니다. 답변에는 더 나은 컨텍스트를 위해 원본 메시지에 대한 참조가 포함됩니다. |
| **편집** | 메시지를 보낸 후 메시지를 업데이트합니다. 편집된 메시지가 채팅의 원본 메시지를 대체합니다. |
| **삭제** | 채팅에서 메시지를 제거합니다. &quot;삭제된 메시지&quot; 레이블이 표시되어 대화의 흐름을 유지합니다. |

## 비공개 메시지 보내기

**개인** 탭을 사용하면 공개 채팅에서 메시지를 공유하지 않고 세션 중에 다른 참가자와 직접 통신할 수 있습니다.

비공개 대화를 시작하려면:

1. **개인** 탭을 선택합니다.

1. 목록에서 참가자를 선택합니다.

   ![개인 채팅 탭](assets/private-chat-tab.png)
   *개인 탭에는 학습자와 다른 참가자 간 일대일 대화가 표시됩니다.*

1. 메시지를 입력하고 **보내기**&#x200B;를 선택합니다.

선택한 참가자와 비공개 대화가 열립니다. 메시지는 사용자와 해당 참가자에게만 표시됩니다.

>[!NOTE]
>
> 개인 채팅 사용 가능성은 세션 설정에 따라 다릅니다. 강사가 개인 채팅을 비활성화하면 개인 대화를 시작하거나 참여할 수 없습니다.
