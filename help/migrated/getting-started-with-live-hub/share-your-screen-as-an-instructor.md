# 강사로 화면 공유

화면 공유를 사용하면 Live Hub 세션 중에 장치의 콘텐츠를 참가자에게 제공할 수 있습니다. 브라우저 탭, 애플리케이션 창 또는 전체 화면을 공유하여 실시간으로 워크플로우를 시연하고, 프레젠테이션을 제공하고, 학습자에게 작업을 안내합니다.

분할 뷰에 최대 2개의 콘텐츠를 나란히 표시하고 공유 콘텐츠와 함께 화이트보드를 사용하여 주요 정보를 강조하기 위해 화면에 직접 주석을 추가하여 프레젠테이션을 향상시킬 수 있습니다. 또한 학습자가 세션에 대한 컨트롤을 유지하면서 화면을 공유하도록 허용할 수 있습니다.

이 문서에서는 Live Hub에서 화면을 공유하고, 콘텐츠에 주석을 달고, 분할 보기를 사용하고, 학습자 화면 공유를 관리하는 방법에 대해 설명합니다.

## 세션에서 화면 공유

세션 중에 화면 공유를 시작하여 실시간으로 모든 참가자에게 콘텐츠를 제공할 수 있습니다. 이를 통해 애플리케이션을 시연하거나, 워크플로우를 살펴보거나, 디바이스에서 직접 프레젠테이션을 제공할 수 있습니다.

화면을 공유하려면 다음 단계를 따르십시오.

1. 컨트롤 막대에서 ![화면 공유](./assets/share-screen-icon.svg)를 선택합니다. 팝업 창이 나타납니다.

1. 다음 중 하나를 선택합니다.

   1. **Chrome 탭**: 브라우저 탭을 공유합니다.

   1. **창**: 특정 응용 프로그램을 공유합니다.

   1. **전체 화면**: 전체 화면을 공유합니다.

   ![전체 화면 공유 옵션](assets/share-entire-screen-option.png)
   *화면 공유를 위한 여러 옵션이 표시된 화면 공유 팝업 창*

1. (선택 사항) 공유 탭의 오디오를 포함하려면 **탭 오디오도 공유**&#x200B;를 사용하도록 설정합니다.

1. 공유하려는 콘텐츠를 선택합니다.

1. **공유**&#x200B;를 선택합니다. 선택한 콘텐츠가 모든 학습자에게 표시됩니다.

세션 중에는 최대 두 개의 콘텐츠를 공유할 수 있습니다. 추가 콘텐츠를 공유하면 레이아웃이 자동으로 조정되어 함께 표시됩니다.

### 화면 공유 중지

화면 공유를 중지하려면 공유 화면 인터페이스에서 **공유 중지**&#x200B;를 선택합니다.

![화면 공유 컨트롤 중지](assets/stop-screen-sharing-control.png)
*화면 공유를 중지하는 옵션이 표시된 컨트롤 막대*

세션의 화면 공유가 종료되고 공유 콘텐츠가 방 인터페이스에서 제거됩니다.

## 한 세션에서 여러 콘텐츠 공유

가상 강의실은 세션 중에 여러 콘텐츠 형식을 공유할 때 분할 보기를 지원합니다. 이를 통해 강사는 화면 공유, 화이트보드 또는 참여도 패널과 같은 둘 이상의 콘텐츠 유형을 동시에 제시할 수 있습니다.

### 분할 보기 작동 방식

여러 콘텐츠가 활성화된 경우:

* 한 번에 최대 두 개의 콘텐츠를 표시할 수 있습니다.

* 메인 무대 영역에는 하나의 콘텐츠가 등장한다.

* 다른 콘텐츠는 보조 보기에 나타납니다.

* 새로운 콘텐츠가 공유되면, 기존 콘텐츠가 보조 뷰로 이동할 수 있다.

>[!NOTE]
>
> 설문과 같은 참여 패널은 우선 순위가 지정되며 분할 보기에서 먼저 표시됩니다.

### 단일 보기로 전환

여러 콘텐츠가 표시되는 경우 강사는 하나의 콘텐츠로 포커스를 전환할 수 있습니다.

단일 보기로 전환하려면 다음을 수행하십시오.

1. 포커스로 가져올 콘텐츠를 선택합니다.

1. **최대화**&#x200B;를 선택합니다. 선택한 콘텐츠는 기본 스테이지에 표시되고, 나머지 콘텐츠는 보조 보기로 이동합니다.

## 화이트보드와 화면 공유 사용

세션 중에 화이트보드와 함께 화면 공유를 실행하여 설명이나 주석을 추가하면서 내용을 표시할 수 있습니다.

활성 화면 공유 중에 화이트보드를 공유하거나 화이트보드가 이미 활성 상태일 때 화면 공유를 시작하면 세션은 자동으로 분할 보기로 전환됩니다.

화이트보드와 화면 공유를 사용하려면:

1. 화면을 공유합니다.

1. 컨트롤 막대에서 화이트보드 아이콘을 선택합니다.

1. **화이트보드 공유**&#x200B;를 선택합니다. 두 컨텐츠 모두 분할 뷰에 표시됩니다.

   ![화면 공유 화이트보드 분할 보기](assets/screen-share-whiteboard-split-view.png)
   *왼쪽의 화이트보드와 오른쪽의 공유 콘텐츠가 있는 분할 보기를 표시하는 라이브 허브 인터페이스.*

화이트보드와 공유 화면 사이에서 포커스를 전환하려면:

1. 보려는 콘텐츠를 선택합니다.

1. **최대화**&#x200B;를 선택합니다. 선택한 콘텐츠가 주 스테이지로 이동합니다. 다른 내용은 보조 보기로 이동합니다.

   ![화면 공유 보조 보기](assets/screen-share-secondary-view.png)
   *인터페이스 하단에 최대 화이트보드와 공유 콘텐츠가 있는 분할 보기를 표시하는 라이브 허브 인터페이스.*

## 공유 콘텐츠에 주석 달기

세션 중에 공유 콘텐츠에 주석을 추가하여 중요한 정보를 강조 표시하거나, 개념을 설명하거나, 학습자를 시각적으로 안내할 수 있습니다. 공유 화면의 스냅샷에 주석이 적용됩니다. 실시간 설명을 위해 설계되었으며 집중적이고 산만함이 없는 경험을 제공합니다.

화면을 공유하는 동안 화면 공유 인터페이스의 오른쪽 상단에 있는 주석(펜) 아이콘을 선택합니다. 주석 도구는 화면 공유 인터페이스에 자동으로 나타납니다.

### 주석 도구 사용

주석 달기를 시작하면 주석 도구 모음이 나타납니다.

![화면 공유 주석 도구 모음](assets/screen-share-annotation-toolbar.png)
*공유 콘텐츠와 상호 작용하기 위한 주석 도구 모음을 보여 주는 라이브 허브 인터페이스*

주석 도구 모음에는 다음과 같은 옵션이 있습니다.

| **도구** | **설명** |
|----|----|
| **선택** | 기존 주석을 관리합니다. 주석 요소를 이동, 크기 조정, 복제 또는 삭제할 수 있습니다. |
| **그리기** | 자유형 드로잉을 만듭니다. 획 Thickness 및 색상을 조정할 수 있습니다. |
| **모양** | 직사각형 또는 원과 같은 구조화된 모양을 추가합니다. 획 및 칠 속성을 사용자 정의할 수 있습니다. |
| **텍스트** | 레이블 또는 설명을 추가합니다. 텍스트 서식을 지정하고 위치를 조정할 수 있습니다. |
| **지우개** | 화면에서 주석을 제거합니다. 개별 요소를 지우거나 모든 주석을 지울 수 있습니다. |
| **주석 달기 중지** | 주석 모드를 종료하고 화면 공유를 다시 시작합니다. 모든 주석이 삭제됩니다. |
| **실행 취소** | 가장 최근 동작을 되돌립니다. |
| **다시 실행** | 이전에 실행 취소한 작업을 다시 적용합니다. |

## 참가자가 화면을 공유하도록 허용

참가자가 세션 중에 화면을 공유하도록 허용할 수 있습니다. 이를 통해 콘텐츠를 제시하고, 워크플로우를 시연하거나, 토론을 지원할 수 있습니다.

학습자에게 화면 공유가 활성화되면:

* 학습자는 세션 컨트롤에서 화면 공유를 시작할 수 있습니다.

* 한 번에 하나의 화면 공유만 활성화할 수 있습니다.

* 강사는 세션 동안 화면 공유에 대한 전체 제어 권한을 유지합니다.
