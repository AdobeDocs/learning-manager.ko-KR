# 학습자로 라이브 허브(Beta) 세션 참여

학습자는 등록된 강의에서 직접 Live Hub 세션에 참여합니다. 가입하면 채팅, 설문 조사, 퀴즈, 화이트보드, 소회의실 등을 통해 실시간 훈련에 참여합니다.

## 세션 참여

1. Adobe Learning Manager에 로그인합니다.

1. **내 학습**&#x200B;으로 이동합니다.

1. 등록한 강의를 선택합니다.

   ![등록된 과정 선택](assets/select-enrolled-course.png)
   *세션으로 이동 을 선택하여 Live Hub 사전 참가 화면을 엽니다.*

1. **시작** > **세션으로 이동**&#x200B;을 선택합니다. Live Hub 조인 인터페이스가 열립니다.

1. (선택 사항) 마이크를 테스트하고 가상 배경을 적용합니다. 자세한 내용은 [Live Hub에서 사전 참가 화면 설정](./setup-pre-join-screen-in-live-hub.md)을 참조하세요.

1. **가입**&#x200B;을 선택합니다.
