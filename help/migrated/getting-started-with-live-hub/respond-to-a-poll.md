# 설문 조사에 응답

학습자는 설문 조사를 통해 Live Hub 세션에 적극적으로 참여할 수 있습니다. 강사가 투표를 시작하면 **투표 및 퀴즈** 패널에 표시되며, 투표 유형에 따라 하나 이상의 옵션을 선택하거나 짧은 텍스트 답변을 입력하여 응답을 제출할 수 있습니다. 투표가 열려 있는 동안 응답을 업데이트할 수 있습니다. 강사가 결과를 공유하면 설문 결과를 실시간으로 볼 수 있습니다. 이 문서에서는 세션 중에 투표에 응답하고 공유된 결과를 보는 방법에 대해 설명합니다.

## 응답 제출

세션 중에 강사가 설문 조사를 시작하면 화면에 표시됩니다. 설문에 응답하려면 설문 유형을 기준으로 다음 중 하나를 수행합니다.

1. **객관식 또는 복수 답변 투표**: 해당 답변 옵션을 선택합니다.

1. **단답형 설문**: 텍스트 필드에 응답을 입력하십시오.

제출하면 **응답이 기록되었습니다** 메시지가 나타납니다.

![설문에 응답](assets/respond-to-poll.png)
*설문 응답을 제출한 후, 귀하의 응답이 기록되었습니다 라는 메시지가 나타납니다.*

## 응답 업데이트

설문 조사가 진행 중인 동안 답변을 변경할 수 있습니다. 설문 조사가 화면에 표시됩니다.

응답을 업데이트하려면 다른 답변 옵션을 선택하거나 텍스트 응답을 편집합니다. 업데이트된 선택 영역이 자동으로 저장됩니다.
