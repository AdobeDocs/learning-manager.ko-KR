# 녹음/녹화 내용 및 대본 이해

Live Hub의 세션 레코딩을 통해 학습자는 세션 및 강사를 다시 방문하여 라이브 세션 이상으로 학습을 확장할 수 있습니다. 각 레코딩은 핵심 강의실 경험을 캡처하고 쉬운 탐색 및 콘텐츠 검색을 지원하는 AI 기반 기능을 사용하여 향상시킵니다.

세션이 종료된 후 기록은 자동으로 처리되며 일반적으로 몇 분 이내에 강의 페이지에서 사용할 수 있습니다. 시스템은 동영상 외에도 AI 기반의 주제, 요약, 녹취록을 생성해 학습자가 전체 녹취록을 보지 않고도 관련 섹션을 빠르게 찾고 검토할 수 있다.

## 레코딩의 주제 기반 탐색

Live Hub는 시간을 기준으로 하는 고정된 장이 아닌 주제별로 녹음을 구성합니다. 세션이 종료된 후 기록 에이전트는 세션 중 동일한 주제에 대한 논의가 서로 다른 지점에서 발생한 경우에도 기록을 분석하고 의미를 기반으로 주제를 식별합니다.

항목은 계정에 대해 **기록 에이전트**&#x200B;에 대한 항목 생성기가 활성화된 경우에만 생성됩니다.자세한 내용은 [Live Hub 사용](../administrators/feature-summary/enable-live-hub.md)을 참조하세요.

예를 들어, 세션 시작 시 주제가 소개되고 토론 중에 재방문되었으며 Q&amp;A 중에 다시 언급되는 경우 Live Hub는 이러한 참조를 동일한 주제의 일부로 인식하고 단일 주제 아래에 그룹화합니다. 검색된 각 항목에 대해 Live Hub는 다음을 생성합니다.

* 제목
* 간단한 설명
* 추가 세부 정보

이 정보는 학습자가 레코딩을 재생하기 전에 주제가 관련성이 있는지 빠르게 판단할 수 있도록 도와줍니다.

## 주요 이점

* **구조화된 대화형 재생**: 선형으로 보는 대신 AI 생성 항목을 사용하여 레코딩을 탐색합니다. 주요 토론 지점으로 빠르게 이동하여 중요한 내용만 검토하십시오.

* **성적 증명서 및 통찰력으로 학습 개선**: 시간이 동기화된 성적 증명서와 함께 따르고 AI에서 생성한 요약과 항목을 활용하여 세션 콘텐츠를 더 잘 이해합니다.

* **유연한 녹음 구성**: 세션 요구 사항에 따라 학습자 비디오, 투표, 채팅 등 녹음에서 캡처되는 내용을 제어합니다.
