# 시스템 요구 사항

Adobe Learning Manager에서 라이브 허브 세션을 구성하고 실행하려면 다음 시스템 요구 사항을 사용하십시오. 라이브 허브는 실행되는 가상 강의실 환경과 동일한 브라우저, 운영 체제 및 하드웨어 요구 사항을 사용합니다.

라이브 허브는 가상 강의실 세션 내에서 사용할 수 있으며 별도의 클라이언트 설치가 필요하지 않습니다.

| 카테고리 | 요구 사항 |
|---|---|
| **데스크톱 브라우저** | 최신 버전의 Google Chrome, Mozilla Firefox, Microsoft Edge 및 Safari |
| **모바일 브라우저** | Chrome 모바일, Safari 모바일 및 Samsung Internet |
| **운영 체제** | Windows 10 이상, macOS 15 이상 |
| **화면 해상도** | 1920 × 1080, 1366 × 768, 768 × 1024(태블릿) 및 375 × 667(모바일) |
| **Windows 하드웨어** | 최소 8GB RAM, 8코어 프로세서, Intel® Core™ i5 이상 |
| **Mac 하드웨어** | 최소 16GB RAM, 4코어 프로세서, 3.2GHz 이상 |
| **네트워크** | 라이브 오디오, 비디오 및 AI 기반 라이브 허브 기능에 최소 5Mbps의 안정적인 광대역 연결 권장 |

>[!NOTE]
>
>Linux 브라우저, Chromebook 디바이스, Firefox Mobile, Opera(데스크탑 및 모바일), Internet Explorer 11 및 이전 브라우저 버전은 지원되지 않습니다.
