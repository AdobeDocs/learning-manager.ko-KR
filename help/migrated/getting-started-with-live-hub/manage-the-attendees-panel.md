# 참석자 패널 관리

**참석자** 패널을 사용하여 Live Hub 세션의 참가자를 보고 관리합니다. 패널에는 세션에 참여했던 학습자와 등록했지만 아직 참여하지 않은 학습자를 포함하여 참석자의 실시간 목록이 표시됩니다. 또한 각 참석자의 역할과 상호 작용 상태가 표시됩니다.

강사는 참석자 패널을 사용하여 학습자의 참여를 관리하고, 참석자 권한을 구성하고, 세션 중에 상호 작용을 중재할 수 있습니다. 마이크 음소거, 들어 올린 손 낮추기, 개인 메시지 보내기, 세션에서 학습자 제거 등의 동작을 수행할 수 있습니다.

이 문서에서는 Live Hub 세션 중 [참석자] 패널에 액세스하고 학습자를 관리하는 방법에 대해 설명합니다.

## 참석자 패널 보기

**참석자** 패널에 세션의 모든 사용자가 표시됩니다. 이 대화 상자를 열려면 컨트롤 막대에서 ![open-participants-panel](./assets/open-attendees.svg)을(를) 선택합니다. 패널에 참가자가 가입하거나 탈퇴하면 모든 학습자와 업데이트가 자동으로 나열됩니다.

![참석자 패널 개요](assets/attendees-panel-overview.png)
*참석자 패널을 표시하는 Live Hub 인터페이스*

패널에서는 다음 옵션을 사용할 수 있습니다.

| **옵션** | **설명** |
|----|----|
| **검색** | **검색** 필드에 입력하여 참가자를 찾습니다. 입력하는 동안 목록이 필터링됩니다. |
| **현재** | 학습자가 현재 세션에 있는 상태를 역할(예: 강사) 및 마이크 상태와 함께 표시합니다. 괄호 안의 숫자는 표시되는 수를 나타냅니다. |
| **가입되지 않음** | 세션에 등록한 학습자 중 아직 가입하지 않은 학습자를 표시합니다. 화살표를 선택하여 목록을 확장합니다. |

## 참석자 패널 설정

참석자 환경 설정을 관리하려면:

1. **참석자** 패널에서 **기타 옵션(⋯)**&#x200B;을 선택합니다.

1. 다음과 같이 사용 가능한 작업을 수행할 수 있습니다.

   1. **모든 손 내리기**: 참가자의 모든 손을 내립니다.

   1. **모든 참가자 음소거**: 모든 참가자의 마이크를 음소거합니다.

   1. **모든 참가자의 카메라 끄기**: 모든 참가자의 카메라 끄기.

## 세션 중 학습자 관리

**참석자** 패널을 사용하면 세션 중에 개별 학습자를 관리할 수 있습니다. 필요한 경우 특정 학습자가 마이크 음소거, 손을 올림, 개인 메시지 전송 또는 프로필 보기 등의 작업을 통해 상호 작용을 중재하고 빠른 작업을 수행하여 구성된 학습 환경을 유지할 수 있습니다.

학습자 권한을 업데이트하려면 다음을 수행합니다.

1. **참석자** 패널에서 학습자로 이동합니다.

1. 학습자 이름 옆의 **기타 옵션(⋯)** 아이콘을 선택합니다.

   ![학습자 기타 옵션 메뉴](assets/learner-more-options-menu.png)
   *참석자 패널에서 학습자의 동작을 표시하는 기타 옵션 메뉴*

1. 다음 동작 중 하나를 선택합니다.

| **작업** | **설명** |
|----|----|
| **음소거** | 학습자의 마이크를 끕니다. |
| **아래쪽** | 학습자의 손을 들어 올려 놓은 표시기를 제거합니다. |
| **개인 메시지 보내기** | 학습자와 비공개 채팅을 엽니다. |
| **세션에서 제거** | 세션에서 학습자를 제거합니다. |
| **프로필 보기** | 학습자의 프로필 정보를 표시합니다. |
