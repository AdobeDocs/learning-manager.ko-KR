# 퀴즈 정보

라이브 허브의 퀴즈 기능을 사용하면 강사가 퀴즈를 만들고 수행하여 라이브 세션 중에 학습자의 이해를 평가할 수 있습니다. 세션 전이나 세션 중에 퀴즈를 생성하고 퀴즈를 실행하여 실시간으로 응답을 수집하고 세션 대시보드에서 학습자가 응답할 때 결과를 모니터링할 수 있습니다.

>[!NOTE]
>
> Live Hub 세션의 퀴즈는 Adobe Learning Manager의 **퀴즈 만들기 도구**&#x200B;에서 만든 퀴즈와 다릅니다.

## 주요 이점

퀴즈 기능은 다음과 같은 이점을 제공합니다.

* **학습 결과 평가**: 학습자가 수업 후 주요 개념을 얼마나 잘 이해하고 유지했는지 평가합니다.

* **구조화된 평가 수행**: 여러 질문 퀴즈를 만들어 단일 질문 검사 이상으로 주제나 모듈에서 학습자를 평가합니다.

* **개별 성과 추적**: 실시간 퀴즈 결과를 통해 강사는 전체 그룹이 어떻게 수행되고 있는지 빠르게 이해하고 추가적인 설명이 필요할 수 있는 영역을 식별할 수 있습니다.

* **참여 개선**: 대화형 평가를 통해 적극적인 참여를 유도하십시오.

## 역할 및 권한

퀴즈 환경은 라이브 허브 세션에서 강사와 학습자 모두 사용할 수 있습니다. 사용 가능한 작업은 사용자 역할에 따라 다릅니다.
