# 투표 정보

설문 조사 기능을 사용하면 강사가 실시간 세션 중에 설문 조사를 만들어 실행하여 학습자의 응답을 실시간으로 수집할 수 있습니다. 객관식, 복수 대답 또는 단답과 같은 질문 유형을 선택하여 수동으로 폴링을 작성하거나 Icebreaker 폴링 및 지식 검사 폴과 같은 AI 지원 옵션을 사용하여 빠르게 폴링을 생성할 수 있습니다.

학습자는 활성 투표에 응답하고, 대답을 업데이트하고, 공유된 결과를 볼 수 있습니다. 모든 설문 활동은 **설문 및 퀴즈** 패널에서 관리됩니다.

## 주요 이점

* **학습자 참여도 높이기**: 학습자가 세션 중에 질문에 응답하는 것을 경청하는 것을 넘어 적극적인 참여를 유도합니다.

* **실시간 이해 확인**: 학습자가 주제를 얼마나 잘 이해하는지 평가하고 추가 설명이 필요할 수 있는 영역을 식별합니다.

* **아이스브레이커로 세션 시작**: 세션 시작 시 설문을 사용하여 참가자를 따뜻하게 만들고, 조기 상호 작용을 장려하고, 보다 매력적인 학습 환경을 만듭니다.

* **즉각적인 피드백 수집**: 진행 중인 지침이나 콘텐츠 공유를 일시 중지하지 않고 세션을 계속 진행하는 동안 학습자의 의견, 환경 설정 또는 피드백을 실시간으로 수집합니다.
