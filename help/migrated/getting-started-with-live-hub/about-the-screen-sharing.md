# 화면 공유 정보

화면 공유를 통해 강사는 자신의 디바이스에서 참여자와 실시간으로 콘텐츠를 공유할 수 있습니다. 화면 공유를 사용하여 응용 프로그램 프레젠테이션, 프레젠테이션 전달, 워크플로 시연 및 학습자 작업 안내합니다. 강사가 화면 공유를 활성화하면 학습자는 자신의 화면을 공유할 수도 있습니다.

화면 공유 외에도 분할 뷰에서 두 내용을 나란히 표시하고, 공유 내용과 함께 화이트보드를 사용하고, 화면에서 직접 주석을 작성하여 프레젠테이션을 중단하지 않고 주요 정보를 강조 표시할 수 있습니다.

## 주요 이점

* **실시간 프레젠테이션**: 장치에서 응용 프로그램, 프레젠테이션 및 워크플로우를 직접 공유하면 학습자가 따라 할 수 있습니다.

* **한 번에 더 보기**: 화면 공유 및 화이트보드와 같이 앞뒤로 전환하지 않고 분할 뷰에 최대 두 개의 콘텐츠를 나란히 표시합니다.

* **시각적으로 설명**: 공유 콘텐츠에 직접 주석을 추가하여 주요 사항을 강조하고, 개념을 명확히 하고, 학습자의 관심을 유도합니다.

* **도구 결합**: 화이트보드를 공유 화면과 함께 실행하여 설명과 메모를 추가합니다.

* **참여 독려**: 강사가 세션을 완전히 제어하는 동안 학습자가 자신의 화면을 공유하여 작품을 발표하거나 토론을 지원하도록 합니다.
