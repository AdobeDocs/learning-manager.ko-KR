# 모바일의 라이브 허브를 학습자로 사용

Adobe Learning Manager 모바일 앱을 사용하여 iOS 또는 Android 디바이스에서 Live Hub 세션에 참여하고 참여할 수 있습니다. 세션 동안 강사 및 참가자와 상호 작용하고, 설문 조사 및 퀴즈에 응답하고, 소회의실에서 공동 작업하고, 모바일 디바이스에서 직접 공유 콘텐츠에 액세스할 수 있습니다.

>[!NOTE]
>
> 모바일 앱은 핵심 Live Hub 참여 기능을 지원합니다. 데스크탑 환경에서 사용할 수 있는 일부 기능은 모바일 장치에서 사용할 수 없습니다. 데스크톱에서 지원되는 전체 기능 목록은 [라이브 허브 시작하기](./getting-started-live-hub.md)를 참조하세요.

## 모바일에서의 학습자 경험

다음 표에는 모바일 앱에서 학습자가 사용할 수 있는 라이브 허브 기능이 요약되어 있습니다.

| **기능** | **모바일 환경** |
|----|----|
| 세션 참가 | Adobe Learning Manager 모바일 앱에서 Live Hub 세션에 참여합니다. |
| 오디오 및 비디오 | 마이크와 카메라를 켜거나 끄고 사용 가능한 오디오 장치를 선택합니다. |
| 채팅 및 질문 | 채팅 대화에 참여하고 세션 중에 질문을 제출합니다. |
| 반응 및 손 올리기 | 강사와 소통하기 위해 반응을 보내고 손을 들어 보세요. |
| 투표 | 세션 중에 게시된 투표에 응답합니다. |
| 퀴즈 | 강사가 실행한 퀴즈를 시도합니다. |
| 소회의실 | 할당된 소회의실에 참여하고, 다른 참가자와 공동 작업하고, 강사 지원을 요청하고, 소회의실 요약을 볼 수 있습니다. |
| 화이트보드 및 공유 콘텐츠 | 세션 중에 공유된 콘텐츠를 보고 상호 작용합니다. |
| 미로 보드 | 강사가 공유한 Miro 게시판을 봅니다. |
| 폐쇄 자막 | 세션 중에 폐쇄 자막을 켜거나 끕니다. |
| 화면 공유 | 강사 또는 참가자가 공유한 콘텐츠를 봅니다. |
| 세션 레코딩 | 세션 후에 레코딩을 사용할 수 있게 되면 레코딩에 액세스합니다. |

## Live Hub 세션 참여

Adobe Learning Manager 모바일 앱에서 예정된 라이브 허브 세션에 참여합니다.

가입하기 전에 카메라, 마이크 및 오디오 장치 설정을 검토하여 올바르게 구성되었는지 확인할 수 있습니다.

![모바일 사전 참가 화면](assets/mobile-pre-join-screen.png)
*모바일에서 Live Hub 세션에 참여하기 전에 카메라, 마이크 및 오디오 장치 설정을 검토하십시오.*

>[!NOTE]
>
> 가상 배경 및 배경 흐림 효과는 모바일 앱에서 지원되지 않습니다.

## 세션 인터페이스 탐색

세션에 참여한 후 기본 세션 보기에는 커뮤니케이션 및 참여 컨트롤과 함께 참여자 비디오 타일 또는 공유 콘텐츠가 표시됩니다.

세션 컨트롤을 사용하여 다음을 수행할 수 있습니다.

* 마이크 켜기 또는 끄기.

* 카메라를 켜거나 끕니다.

* 손 들어

* 반응들을 보냅니다.

* 채팅 및 질문에 액세스합니다.

* 설문 및 퀴즈에 참여합니다.

* 소회의실 활동에 참여하십시오.

* 세션에서 나갑니다.

## 폐쇄 캡션 사용

폐쇄 캡션을 사용하면 세션 중에 음성 콘텐츠를 팔로우할 수 있습니다.

라이브 허브 세션에 참석하는 동안 언제든지 캡션을 켜거나 끌 수 있습니다.

>[!NOTE]
>
> 글꼴 크기 및 표시 스타일과 같은 캡션 서식 옵션은 모바일 앱에서 사용할 수 없습니다.

## 채팅에서 질문

채팅 패널을 사용하여 강사 및 다른 참가자와 소통합니다.

다음을 수행할 수 있습니다.

* 세션 채팅에 메시지를 게시합니다.

* 강사 및 참가자의 메시지를 봅니다.

* 세션 중에 질문을 제출합니다.

* 강사가 제공한 응답을 검토합니다.

## 설문 조사에 응답

강사가 설문 조사를 시작하면 세션에 자동으로 나타납니다.

![모바일 설문 조사에 응답](assets/mobile-respond-to-poll.png)
*Adobe Learning Manager 모바일 앱에서 직접 투표에 응답합니다.*

모바일 앱에서 직접 응답을 제출할 수 있습니다. 폴링 구성 방법에 따라 응답 후 폴링 결과를 볼 수도 있습니다.

## 퀴즈 시도

강사가 퀴즈를 시작하면 세션에서 나가지 않고 모바일 디바이스에서 퀴즈를 완료할 수 있습니다.

퀴즈 결과 및 대답 표시 여부는 강사가 구성한 설정에 따라 달라집니다.

## 소회의실 참여

세션 중에 소회의실을 사용하는 경우 강사가 회의실에 배정합니다.

![모바일 소회의실 보기](assets/mobile-breakout-room-view.png)
*모바일에서 사용할 수 있는 공동 작업 옵션을 보여주는 소회의실 보기*

브레이크아웃 룸에서는 다음과 같은 작업을 수행할 수 있습니다.

* 다른 참여자와 공동 작업을 수행하세요.

* 브레이크아웃 활동에 참여하세요.

* 강사에게 지원을 요청합니다.

* 소급 요약이 있으면 검토하십시오.

소회의실 할당과 시간은 강사가 관리합니다.

## 공유된 내용 보기

세션 중에 강사는 프레젠테이션, 화이트보드, Miro 보드 또는 기타 콘텐츠를 공유할 수 있습니다. 모바일 앱에서 바로 공유 콘텐츠를 보고 토론 및 활동을 따라 할 수 있습니다.

![모바일 보기 공유 콘텐츠](assets/mobile-view-shared-content.png)
*강사가 모바일 앱에서 직접 공유한 콘텐츠를 봅니다.*

## 세션 나가기

세션을 종료할 준비가 되면 **나가기**&#x200B;를 선택합니다.

![모바일 나가기 세션](assets/mobile-leave-session.png)
*모바일 앱에서 세션을 종료하려면 [나가기]를 선택하십시오.*

나가면 세션 경험에 대한 피드백을 제공하라는 메시지가 표시됩니다.
