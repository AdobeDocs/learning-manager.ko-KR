# 브레이크아웃 정보

강사는 소회의실에서 라이브 허브 세션을 여러 개의 작은 그룹으로 나눌 수 있습니다. 학습자는 토론, 활동 또는 공동 작업을 위해 이러한 회의실에 참여하고 활동이 종료되면 자동으로 기본 세션으로 돌아갑니다. 브레이크아웃실은 브레인스토밍, 모둠 활동, 집중학습에 유용하다.

강사는 지침으로 소회의실을 생성 및 관리하고 학습자를 할당하며 활동을 안내할 수 있다. 세션 동안 강사는 회의실 활동을 모니터링하고 실시간 토론 요약을 볼 수 있으며 필요할 때 지원을 제공할 수 있습니다.

학습자는 할당된 회의실 내에서 공동 작업을 수행하고, 토론에 참여하며, 공유된 지침과 요약을 사용하여 활동에 맞게 정렬됩니다.

세션 종료 후 강사는 세션 보고서와 세션 대시보드를 통해 파업토의와 결과물을 검토할 수 있어 보다 나은 분석과 후속 조치가 가능하다.

## 브레이크아웃 세션의 이점

* **공동 작업을 장려합니다**:Participants 더 작은 그룹에서 공동 작업을 수행하여 집중된 토론 및 활동을 진행할 수 있습니다.

* **실시간 회의실 가시성**: 강사는 참가자를 방해하지 않고 회의실 간의 참여, 참여 및 도움말 요청을 모니터링할 수 있습니다.

* **AI 기반 토론 인사이트**: 실시간 요약은 강사가 회의실 간의 토론을 빠르게 이해하고 활동을 효과적으로 안내하는 데 도움이 됩니다.

* **구조화된 활동 지침**: 브레이크아웃 활동 중 학습자를 안내하는 지침을 제공합니다.

* **유연한 참가자 관리**: 참가자를 손쉽게 할당하고 조정하여 다른 학습 형식을 지원할 수 있습니다.

* **세션 후 인사이트 및 보고**: 강사는 세션 대시보드에서 요약, 보고서 및 세션 데이터를 검토하여 결과를 분석하고 향후 세션을 개선할 수 있습니다.

## 브레이크아웃 세션 용어

이 약관은 브레이크아웃 세션이 작동하는 방식과 참가자가 활동 중에 상호 작용하는 방식을 설명합니다.

| **용어** | **설명** |
|----|----|
| **브레이크아웃 세션** | 참가자들이 소규모 그룹으로 나뉘어 집중적인 토론이나 활동을 진행하는 가상 강의실에서의 임시 세션 |
| **소회의실** | 학습자가 특정 활동에 참여하도록 나뉘어 있는 소규모 세션 내의 그룹입니다. |
| **브레이크아웃 지침** | 강사는 해당 과제나 토론을 소회의실 참여자에게 배정합니다. |
| **브레이크아웃 보고서** | 강사가 참여 수준을 모니터링하고 평가하는 데 사용하는 브레이크아웃 세션 중 학습자의 참여도 측정값입니다. |

## 브레이크아웃 세션 워크플로우

브레이크아웃 세션은 설정, 실시간 공동 작업 및 세션 완료를 포함하는 구조화된 플로우를 따릅니다.

### 브레이크아웃 세션 설정

강사는 브레이크아웃 세션을 시작하기 전에 세션의 요구 사항에 따라 브레이크아웃 룸을 만들고 구성합니다.

* 소회의실 수를 정의합니다.

* 참가자를 드래그 앤 드롭하여 학습자를 자동으로 또는 수동으로 룸에 할당합니다.

* 활동 지침을 추가하여 학습자를 안내합니다.

이러한 설정을 통해 세션 시작 전에 학습자를 활동에 맞게 구성하고 정렬할 수 있습니다.

### 브레이크아웃 세션 중

브레이크아웃 세션이 시작되면 학습자는 할당된 회의실로 이동하여 주어진 활동에 공동 작업을 수행합니다.

* 학습자는 자신의 소회의실 내에서 상호 작용하고 참여한다.

* 교수자는 방 활동을 모니터링하고, 참여를 추적하고, 도움 요청에 대응할 수 있다.

* 교수자는 토론의 실시간 요약을 볼 수 있고, 필요할 때 강의실에 가입하여 학습자를 안내할 수 있다.

이 단계는 협업과 적극적인 참여에 초점을 두고 있다.

### 브레이크아웃 세션 이후

브레이크아웃 세션이 종료되면 모든 참가자는 자동으로 다시 회의실로 이동합니다.

* 학습자는 기본 세션 보기로 돌아갑니다.

* 교수자는 보고서를 통해 전반적인 활동, 결과, 세션 요약을 검토할 수 있다.

* 강사는 중복 세션을 만들어 동일한 설정을 향후 활동에 다시 사용할 수 있습니다.

이렇게 하면 브레이크아웃 작업이 완료되고 세션 후 검토가 활성화됩니다.
