# 화이트보드를 학습자로 사용

화이트보드는 라이브 허브 세션 중에 시각적 공유 작업 영역을 제공합니다. 강사가 화이트보드 액세스를 활성화하면 공유 캔버스에서 모양 및 텍스트를 그리고 추가하고 내용을 지울 수 있습니다. 화이트보드를 사용하여 아이디어를 설명하고, 문제를 해결하고, 실시간 공동 작업 활동에 참여하세요.

이 문서에서는 학습자로 라이브 허브의 화이트보드를 사용하는 방법에 대해 설명합니다.

## 화이트보드 사용

강사가 학습자로 하여금 화이트보드를 편집하도록 허용하면 라이브 세션 중에 화이트보드와 상호 작용할 수 있습니다. 이 세션에서 다음을 수행할 수 있습니다.

* 마커 도구를 사용하여 화이트보드에 그립니다.

* 모양 및 텍스트를 추가하여 콘텐츠를 만들거나 제공할 수 있습니다.

* 화이트보드에서 그림, 모양 또는 개체를 지웁니다.

![학습자 화이트보드 도구](assets/learner-whiteboard-tools.png)
*학습자는 공유 화이트보드에서 모양을 그리고, 모양과 텍스트를 추가하고, 내용을 지울 수 있습니다.*
