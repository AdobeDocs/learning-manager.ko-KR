# 라이브 허브 문제 해결 가이드

Live Hub 세션 중에 강사에게 오류 메시지나 알림이 발생하여 특정 작업이 예상대로 완료되지 못할 수 있습니다. 이 문서에서는 일반적인 강사 대상 오류, 가능한 원인 및 이러한 오류를 해결하기 위해 취할 수 있는 단계에 대해 설명합니다.

## 연결 문제

| 오류 메시지 | 시나리오 | 오류를 극복하기 위한 제안 사항 |
|---|---|---|
| 오류가 발생했습니다. 다시 시도하십시오. | 일반적인 연결 또는 세션 관련 오류가 발생합니다. 예를 들어, 세션에 참여하거나 세션과 상호 작용할 때 네트워크 불안정성, 만료된 ALM 세션 또는 동일한 회의에 열려 있는 여러 탭과 같은 충돌하는 브라우저 상태로 인해 요청이 실패합니다. | <ul><li>네트워크 연결을 확인하고 VPN/프록시 간섭 없이 안정적인 대역폭을 확보하십시오.</li><li>유효한 세션으로 ALM에 로그인했는지 확인합니다. 세션이 만료된 경우 로그아웃했다가 다시 로그인합니다.</li><li>동시에 여러 탭에서 동일한 회의에 참가하지 마십시오.</li><li>시크릿/비공개 창을 시도하거나 문제가 지속되면 브라우저 캐시를 지우십시오.</li><li>페이지 새로 고침 — 대부분의 일시적인 오류는 다시 로드한 후 해결됩니다. 오류가 반복되면 지원 센터에 문의하십시오.</li></ul> |

## 퀴즈 탭 문제

아래 메시지는 강사가 퀴즈를 생성하거나 시작하는데 퀴즈가 퀴즈를 시작하는 데 필요한 요구 사항을 충족하지 않을 때 나타납니다.

| 오류 메시지 | 시나리오 | 오류를 극복하기 위한 제안 사항 |
|---|---|---|
| 계속하려면 질문을 입력하십시오. | 강사가 질문 텍스트를 입력하지 않고 퀴즈를 실행하려고 합니다. | 질문을 입력하고 대답 옵션을 입력한 다음 정답을 선택하고 참가자를 위한 퀴즈를 시작합니다. |
| 대답 옵션은 비워 둘 수 없습니다. | 강사가 질문 텍스트를 입력하지만 답변 옵션을 입력하지 않거나 하나 이상의 답변 옵션을 비워 둡니다. | 질문을 입력하고 대답 옵션을 입력한 다음 정답을 선택하고 참가자를 위한 퀴즈를 시작합니다. |
| 정답을 표시합니다. | 강사가 질문과 대답 옵션을 입력하지만 정답 옵션은 선택하지 않습니다. | 질문을 입력하고 대답 옵션을 입력한 다음 정답을 선택하고 참가자를 위한 퀴즈를 시작합니다. |

## 설문 탭 문제

강사가 폴링을 복제, 삭제 또는 재설정할 때 아래 메시지가 나타날 수 있습니다.

| 오류 메시지 | 시나리오 | 오류를 극복하기 위한 제안 사항 |
|---|---|---|
| 설문을 복제할 수 없습니다. 다시 시도하십시오. | 강사가 기존 설문을 복제하여 복제가 생성되지 않습니다. | [설문 및 퀴즈] 패널을 닫고 설문 복제를 다시 시도합니다. |
| 모든 설문을 삭제하지 못했습니다. 다시 시도하십시오. | 강사는 모두 삭제 를 사용하여 모든 폴링을 한 번에 삭제하며, 일괄 삭제는 실패하거나 부분적으로만 완료됩니다. | [투표 및 퀴즈] 패널을 닫고 [모든 투표 삭제]를 사용하여 투표 삭제를 다시 시도합니다. |
| 설문을 삭제하지 못했습니다. 다시 시도하십시오. | 강사가 단일 폴링을 삭제하며 삭제가 완료되지 않습니다. | [설문 및 퀴즈] 패널을 닫고 설문 삭제를 다시 시도합니다. |
| 설문을 다시 설정할 수 없습니다. 다시 시도하십시오. | 강사가 이전에 실행한 설문을 재설정하여 재사용할 수 있도록 하며 재설정이 완료되지 않습니다. | [설문 및 퀴즈] 패널을 닫고 설문 재설정을 다시 시도하십시오. |

## 콘텐츠 업로드 문제

아래 메시지는 강사가 AI 비서가 질문에 답변하는 데 사용하는 참조 파일을 업로드할 때 표시될 수 있습니다.

| 오류 메시지 | 시나리오 | 오류를 극복하기 위한 제안 사항 |
|---|---|---|
| 파일을 처리할 수 없습니다. 다시 시도하십시오. | 강사는 처리할 수 없는 손상된 파일, 빈 파일 또는 암호로 보호된 파일을 업로드합니다. | 파일을 지원되는 형식(PDF 또는 PPT)으로 변환하고 다시 업로드합니다. |

## 콘텐츠 업로드 토스트 문제

아래 메시지는 강사가 AI 도우미에서 사용할 참조 파일을 업로드하고 파일이 특정 유효성 검사를 통과하지 못할 때 토스트 알림으로 표시됩니다.

| 오류 메시지 | 시나리오 | 오류를 극복하기 위한 제안 사항 |
|---|---|---|
| 파일을 처리할 수 없습니다. 파일을 확인하고 다시 시도하십시오. | 강사가 손상된 파일을 업로드합니다. | 파일 형식을 확인하고 지원되는 형식(PDF 또는 PPT)으로 변환한 다음 다시 업로드합니다. |
| 파일이 암호로 보호되어 있습니다. 암호를 제거하고 다시 업로드하십시오. | 강사가 암호로 보호된 파일을 업로드합니다. | 파일에서 암호 보호를 제거한 다음 다시 업로드하십시오. |
| 파일에 처리할 콘텐츠가 없습니다. 텍스트 콘텐츠가 포함된 파일을 업로드해 주십시오. | 강사가 AI 비서가 처리할 콘텐츠가 없는 파일을 업로드합니다. | 텍스트 콘텐츠가 포함된 파일을 업로드합니다. |
| &quot;FileName.pdf&quot;가 1MB 제한을 초과합니다. | 강사가 1MB 파일 크기 제한을 초과하는 PDF 파일을 업로드합니다. | PDF 파일 크기를 1MB 미만으로 압축 또는 줄인 다음 다시 업로드합니다. |
| &quot;FileName.pptx&quot;가 3MB 제한을 초과합니다. | 강사가 3MB 파일 크기 제한을 초과하는 PPT 파일을 업로드합니다. | PPT 파일 크기를 3MB 미만으로 압축 또는 줄인 다음 다시 업로드합니다. |

## 브레이크아웃 세션 문제

아래 메시지는 강사가 브레이크아웃 세션을 시작하려고 할 때 표시될 수 있습니다.

| 오류 메시지 | 시나리오 | 오류를 극복하기 위한 제안 사항 |
|---|---|---|
| 브레이크아웃을 시작할 수 없습니다. 연결이 중단되었습니다. 다시 연결되면 다시 시도하십시오. | 강사는 연결이 현재 중단되거나 다시 연결되는 동안 소회의실을 시작하려고 합니다. | 연결이 안정될 때까지 기다린 다음(다시 연결 표시기를 확인합니다) 소회의실을 다시 시작합니다. |
| 브레이크아웃을 시작할 수 없습니다. 다시 시도하십시오. | 강사가 소회의실을 시작하고, 이를 시작하라는 요청이 실패합니다. | 소규모 회의실을 다시 시작하십시오. 문제가 계속되면 [브레이크아웃] 패널을 닫고 다시 시도하십시오. |
| 요약을 생성할 수 없습니다. | 이 문제는 다음과 같은 상황에서 발생할 수 있습니다. <ul><li>세션 중에 말하는 사용자가 없으므로 요약할 오디오 콘텐츠가 없습니다.</li><li>토론은 60초 미만입니다.</li></ul> | 참가자가 세션 중에 60초 이상 적극적으로 발언해야 요약을 생성할 수 있습니다. 문제가 지속되면 잠시 기다린 후 다시 시도하십시오. |

## 토스트 문제에 대한 답변 생성

아래 메시지는 강사가 AI 도우미에게 채팅에서 참가자의 질문에 대한 답변을 생성하도록 요청할 때 표시될 수 있습니다.

| 오류 메시지 | 시나리오 | 오류를 극복하기 위한 제안 사항 |
|---|---|---|
| 이 내용은 세션에서 다루지 않았습니다. | 학습자는 업로드된 콘텐츠 참조에서 다루지 않은 질문을 합니다. 이는 예상된 동작이며 오류가 아닙니다. | 질문에 수동으로 답변합니다. |
