# 모델 컨텍스트 프로토콜 서버용 학습자 도구

학습자가 연결되면 모든 기능이 로그인 학습자로 실행됩니다. 요청은 학습자가 Adobe Learning Manager에서 액세스할 수 있는 항목만 반환합니다. 자세한 내용은 [AI 클라이언트 연결](/help/migrated/learners/feature-summary/connect-ai-client-to-alm-learner.md)을 참조하세요.

## 학습자 기능

| **기능** | **학습자가 할 수 있는 작업** | **요청 예시** |
|----|----|----|
| 학습 콘텐츠 검색 | 강의, 인증 및 학습 경로 찾기 | 어떤 리더십 과정을 이용할 수 있습니까? |
| 등록 보기 | 등록 및 기한 학습 확인 | 내 강의 중 만료 예정 강의는 무엇입니까? |
| 학습 관련 질문 | 학습 콘텐츠에서 답변 받기 | FedRAMP에서 공급망 리스크 관리는 무엇을 의미합니까? |
| 학습 경로 생성 | 개인화된 학습 경로 생성 | 프로젝트 관리 기술을 향상하는 강의를 찾도록 도와주십시오. |
| 학습 경로 저장 | 생성된 학습 경로 저장 | 이 학습 경로를 저장합니다. |

## 지원되는 MCP 도구

학습자 도우미 MCP 서버는 다음과 같은 학습자 대면 도구를 공개한다.

| **MCP 도구** | **목적** | **기능 지원** |
|----|----|----|
| 검색 | 사용 가능한 학습 콘텐츠 검색 | 학습 콘텐츠 검색 |
| 등록 받기 | 학습자 등록 정보 검색 | 등록 보기 |
| 응답 에이전트 | 학습 콘텐츠를 사용하여 질문에 답변 | 학습 관련 질문 |
| 사용자 가져오기 | 각 요청에 로그인한 학습자 식별 | 모든 기능 |
| 학습 객체 가져오기 | 설명 및 기간과 같은 학습 객체의 세부 정보 검색 | 학습 콘텐츠 검색, 등록 보기 |
| 학습 경로 생성 | 추천 학습 경로 만들기 | 학습 경로 생성 |
| 학습 경로 저장 | 생성된 학습 경로 저장 | 학습 경로 저장 |

>[!IMPORTANT]
>
>도구 이름은 참조용으로 표시되며 클라이언트 구현에 따라 다를 수 있습니다.
