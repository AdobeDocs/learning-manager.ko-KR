# AI 클라이언트를 Adobe Learning Manager에 연결

통합 책임자는 먼저 커넥터를 설정해야 합니다. Adobe Learning Manager 커넥터가 표시되지 않으면 관리자에게 문의하십시오. **클라이언트는 Adobe Learning Manager Ultimate 계층**&#x200B;에서만 사용할 수 있습니다.

관리자는 [AI 클라이언트에 Adobe Learning Manager 추가](/help/migrated/administrators/feature-summary/add-alm-to-ai-client.md)를 참조할 수 있습니다.

1. Claude 또는 ChatGPT Enterprise와 같은 조직의 AI 클라이언트를 엽니다.
2. 커넥터 목록에서 Adobe Learning Manager 커넥터를 찾습니다.
3. **연결**&#x200B;을 선택합니다.
4. 메시지가 표시되면 Enterprise ID로 로그인합니다.
5. 학습에 대해 질문해 보십시오. 아이디어는 **학습자를 위한 샘플 프롬프트**&#x200B;를 참조하세요.

>[!NOTE]
>
>한 번 로그인하십시오. 요청은 자체 권한으로 실행되므로 Adobe Learning Manager에서 액세스할 수 있는 항목만 표시됩니다.

## 문제 해결

**커넥터를 찾을 수 없습니다**

관리자에게 커넥터를 활성화하도록 요청하십시오.

**AI 클라이언트가 이전 질문을 기억하지 못합니다**

각 요청은 새 요청으로 처리됩니다. 대화가 계속되는지 여부는 AI 클라이언트에 따라 달라집니다. 다음 질문에서 세부 사항을 반복합니다.

**AI 클라이언트가 Adobe Learning Manager 커넥터를 호출하지 않습니다**

등록 또는 강의 주제 등 질문에서 원하는 항목의 이름을 지정합니다.
