# 학습자로 Claude에 Adobe Learning Manager 추가

조직에서 아직 커넥터를 추가하지 않은 경우에만 다음 단계를 수행하십시오. Claude에 Adobe Learning Manager 커넥터가 표시되는 경우 대신 **연결**&#x200B;을 선택하십시오.

## Claude에서 커넥터 추가

1. 클라우드에서 **사용자 지정** \> **커넥터**&#x200B;로 이동합니다.
2. **추가**(**+**)을 선택한 다음 **사용자 지정 커넥터 추가**&#x200B;를 선택합니다.
3. Adobe Learning Manager과 같은 **이름**&#x200B;을 입력하십시오.
4. **원격 MCP 서버 URL**&#x200B;에 MCP 끝점 URL을 입력하십시오.
5. **계속**&#x200B;을 선택합니다.
6. **인증**&#x200B;에서 **지금 로그인**&#x200B;을 유지합니다.
7. **OAuth 클라이언트**&#x200B;에서 **자신의 OAuth 클라이언트 사용**&#x200B;을 선택합니다.
8. **클라이언트 ID**&#x200B;에 클라이언트 ID를 입력하십시오.
9. **클라이언트 암호**&#x200B;에 비밀 키를 입력하십시오.
10. **추가**&#x200B;를 선택합니다.
11. 로그인 페이지가 열리면 Adobe Learning Manager에 로그인합니다.

로그인하면 커넥터가 연결된 것으로 표시됩니다. 학습에 대해 질문해 보십시오. 아이디어는 **학습자를 위한 샘플 프롬프트**&#x200B;를 참조하세요.

>[!IMPORTANT]
>
>Claude는 [클라이언트 시크릿] 필드를 선택 사항으로 표시하지만 Adobe Learning Manager에는 이 필드가 필요합니다. 비워 두거나 잘못된 값을 입력하면 &quot;인증 실패&quot; 메시지와 함께 로그인이 실패합니다.

>[!NOTE]
>
>요청은 사용자 고유의 권한으로 실행됩니다. Claude는 Adobe Learning Manager에서 볼 수 있는 것만 볼 수 있습니다.

## 다른 Adobe Learning Manager 계정 사용

브라우저에 이미 활성 Adobe Learning Manager 세션이 있는 경우 Claude는 자격 증명을 요청하지 않고 해당 계정에 연결합니다. 다른 사용자로 연결하려면 먼저 Adobe Learning Manager에서 로그아웃하거나 비공개 브라우저 창을 사용합니다.

## 기타 AI 클라이언트

ChatGPT 또는 다른 클라이언트의 경우 단계가 다릅니다. 사용자 정의 커넥터를 추가하려면 AI 클라이언트의 설명서를 참조하고 관리자의 동일한 세 가지 값을 사용합니다.

## 문제 해결

**로그인이 등록되지 않은 리디렉션 메시지를 표시합니다.** 관리자는 서버에 대한 **리디렉션 도메인**&#x200B;에 클라우드 도메인을 추가해야 합니다. 관리자에게 <https://claude.ai>을(를) 추가하도록 요청하고 다시 시도하십시오.

**클라우드 님이 권한 부여에 실패했다고 말합니다.** 비밀 키에 공백이 더 있는지 또는 잘못된 값이 있는지 확인합니다. 관리자에서 다시 복사하고 커넥터를 제거한 다음 다시 추가합니다.

**잘못된 사용자로 연결했습니다.** 커넥터 연결을 끊고 Adobe Learning Manager에서 로그아웃한 다음 비공개 브라우저 창에서 다시 연결합니다.

**클라우드에서 다시 로그인하라는 메시지가 표시됩니다.** 세션이 만료되었거나 액세스 권한이 해지되었습니다. **연결**&#x200B;을 선택하여 다시 로그인합니다.
