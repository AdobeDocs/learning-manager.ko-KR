# 학습자 준수 위젯에 다중 등록 강의

Adobe Learning Manager에서 학습자는 동일한 강의의 둘 이상의 인스턴스에 등록할 수 있습니다. 이제 학습자 준수 위젯에 기한이 있는 등록된 모든 인스턴스가 나열되므로 학습자는 기본 인스턴스만 표시되지 않고 각 예정 날짜를 볼 수 있습니다.

## 다중 등록 강의의 변경 사항

이 변경 전에 준수 위젯은 다중 등록 강의의 기본 인스턴스만 표시했습니다. 여러 인스턴스에 등록된 학습자는 위젯에서 다른 인스턴스에 대한 마감일을 볼 수 없습니다.

이제 준수 위젯은 다음 모든 조건을 충족하는 모든 인스턴스를 표시합니다.

* 학습자가 인스턴스에 등록되어 있습니다.
* 인스턴스에 기한이 있습니다.
* 학습자가 인스턴스를 완료하지 않았습니다.

각 항목에 인스턴스 이름이 표시되므로 학습자는 같은 강의의 인스턴스를 구별할 수 있습니다. 학습자가 항목을 선택하면 Adobe Learning Manager에서 해당 인스턴스가 직접 열립니다.

예를 들어 학습자는 초기 교육 과정을 완료합니다. 책임자는 나중에 동일한 강의의 9월, 10월, 11월 버전에 학습자를 등록하고 각각 기한이 부여됩니다. 준수 위젯에는 세 가지 버전이 모두 나열됩니다.

위젯은 각 준수 범주에서 각 인스턴스를 개별적으로 계산합니다. **지연**, **다음 30일 이내에 예정된 기한** 및 **추적 중**.

## 준수 위젯에 나타나는 인스턴스

다음 표에서는 위젯이 각 등록 상황을 처리하는 방법을 설명합니다.

| 등록 상황 | 위젯에 나타납니다 | 노트 |
|--------------------------------------------------|-----------------------------------|---------------------------------------|
| 등록됨, 인스턴스에 마감일이 있으며 완료되지 않음 | 예 | 인스턴스 이름과 함께 표시됨 |
| 등록됨, 인스턴스에 기한 없음 | 아니오 | 기한이 있는 인스턴스만 표시됩니다. |
| 인스턴스 완료됨 | 아니오 | 완료된 인스턴스가 나열되지 않음 |
| 등록된 모든 인스턴스에서 완료됨 | 아니오 | 강의가 더 이상 표시되지 않습니다. |
| 최종 기한이 있는 인스턴스 하나와 없는 인스턴스 하나 | 기한이 있는 인스턴스만 |                                       |
| 등록된 인스턴스 한 개만 | 예 | 위젯이 해당 인스턴스를 표시합니다 |

API 정보는 [학습자 앱의 다중 등록 인스턴스에 대한 API 지원](/help/migrated/api-changes-dec-2026.md#multi-enrolled-compliance-widget)을 참조하십시오.
