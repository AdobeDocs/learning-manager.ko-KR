# Adobe Learning Manager 학습자를 위한 샘플 프롬프트

먼저 AI 클라이언트를 연결해야 합니다. [AI 클라이언트 연결](/help/migrated/learners/feature-summary/connect-ai-client-to-alm-learner.md)을 봅니다. 각 프롬프트는 [학습자 도구 참조](/help/migrated/learners/feature-summary/learner-tools-reference.md)의 도구에 매핑됩니다.

## 등록

| **프롬프트** | **도구** |
|------------------------------------------|----------------|
| 어떤 강의에 등록되어 있습니까? | 등록 받기 |
| 내 강의 중 만료 예정 강의는 무엇입니까? | 등록 받기 |

## 검색

| **프롬프트** | **도구** |
|-----------------------------------------|----------|
| 어떤 리더십 과정을 이용할 수 있습니까? | 검색 |
| 사용할 수 있는 보안 교육을 표시합니다. | 검색 |

## 지식

| **프롬프트** | **도구** |
|---------------------------------------------------------|--------------|
| FedRAMP에서 공급망 리스크 관리는 무엇을 의미합니까? | 상담사 |
| 규정 준수 과정의 요구 사항을 설명합니다. | 상담사 |

## 학습 경로

| **프롬프트** | **도구** |
|----|----|
| 프로젝트 관리 기술을 향상시키기 위한 강의 집합을 찾을 수 있도록 도와주십시오. | 학습 경로 생성 |
| 이 학습 경로를 저장합니다. | 학습 경로 저장 |
