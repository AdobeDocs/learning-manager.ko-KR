# Adobe Learning Manager 2026년 8월 릴리스의 기능 가용성

## 용도

자체 프런트 엔드(&quot;헤드리스&quot; 구현)를 통해 플랫폼을 구축하거나 확장하는 기업 고객은 학습자 API, 관리자 API, AEM 위젯 또는 다른 통합 표면을 통해 새 기능이나 변경된 기능을 표준 웹 UI 외부에서 실제로 사용할 수 있는지 여부를 정기적으로 묻습니다.

이 문서는 이번 릴리스에 포함된 각 기능에 대한 간단한 서술형 답변을 제공합니다. 이 문서에서는 각 기능에 대해 지원되는 응용 프로그램 표면, 통합 가용성, 마이그레이션 지원 및 적용 가능한 모든 알림 동작을 식별합니다.

## 기능별 가용성

### 구성 요소 기반 전자 메일 빌더

기능 릴리스 이후 등록한 다른 계정이 기존 이메일 편집기에서 새 편집기로 해당 계정을 마이그레이션할 수 있도록 이 기능이 단계적으로 활성화됩니다. 활성화되면 고객은 이전 이메일 편집기를 사용할 수 없습니다. (기능 지원을 받으려면 CSM/지원에 문의하십시오.)

* **사용 가능 대상:** 관리자 앱. 관리자와 작성자는 여기에서 전자 메일 레이아웃 및 템플릿을 구성합니다.
* **해당되지 않음:** 학습자가 자신의 메일 클라이언트를 통해 결과 전자 메일을 수신하기만 하므로 학습자 관련 UI, 헤드리스 API 및 AEM 위젯을 사용합니다.
* **알림:**
  * 전자 메일 알림은 지원되는 전자 메일 클라이언트를 통해 학습자에게 계속 전달됩니다.
  * 이 기능에는 새로운 플랫폼 내 알림 동작이 도입되지 않았습니다.

### 외부 학습

* **사용 가능 대상:** 네이티브 웹, 헤드리스(학습자) API, 네이티브 모바일 웹 및 책임자 앱
* **아직 사용할 수 없음:** 기본 모바일 앱.
* **작업 API:**&#x200B;은(는) 해당되지 않습니다.
* **마이그레이션:**&#x200B;은(는) 아직 지원되지 않습니다.
* **알림:**
  * 학습자와 관리자는 외부 학습 승인 요청이 제출되고 요청이 승인 또는 거부되면 플랫폼 내 알림을 사용할 수 있습니다.
  * 현재 이 워크플로우에서는 전자 메일 알림을 사용할 수 없습니다.

### 증분 사용자 보고서

* **사용 가능 대상:** 작업 API 전용. 보고용 사용자 데이터의 변동분(델타) 익스포트를 제공합니다.
* **해당되지 않음:** UI, 기타 API 표면 및 마이그레이션 도구.

### 보고서 작성기

* **사용 가능 대상:** 관리자 앱.
* **작업 API**&#x200B;에서 아직 사용할 수 없습니다. 작업 API 기반 내보내기는 향후 릴리스에서 진행할 예정입니다.
* **마이그레이션:**&#x200B;이(가) 적용되지 않습니다.
* **알림:**
  * 사용자는 보고서 다운로드가 준비되거나 보고서 생성이 실패할 경우 플랫폼 내 알림을 받습니다.
  * 이메일 알림은 적용되지 않습니다.

### 계층 구조 콘텐츠 폴더
