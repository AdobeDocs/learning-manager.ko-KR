# 자가 등록을 위해 로그인하지 않은 메뉴 URL 사용

자체 등록 프로필을 사용하면 파트너 또는 여러 조직의 구성원과 같은 외부 사용자가 Adobe Learning Manager에서 자신의 계정을 만들 수 있습니다. 이제 각 자체 등록 프로필에 대해 로그인하지 않은 메뉴 URL을 공유할 수 있습니다. 메뉴는 Experience Builder에서 기본 제공됩니다.

사용자가 해당 URL을 통해 도달한 페이지에서 **등록**&#x200B;을 선택하면 Adobe Learning Manager은 URL이 속한 프로필에 사용자를 추가합니다. 이렇게 하면 다른 에이전시 또는 파트너 회사와 같은 다른 조직의 사용자를 별도의 프로필에 유지할 수 있습니다.

이전에는 로그인하지 않은 페이지 URL이 항상 **브랜딩**&#x200B;에서 선택한 하나의 프로필에 새 사용자를 추가했습니다. 로그인하지 않은 메뉴 URL은 모든 프로필에 자체 URL이 있고 모든 URL이 동일한 랜딩 페이지를 열 때 이러한 제한을 제거합니다.

## 시작하기 전에

1. Experience Builder에서 로그인하지 않은 메뉴를 만들고 **브랜딩**&#x200B;에서 랜딩 페이지를 선택합니다. 모든 프로필 URL이 랜딩 페이지에서 열립니다.

1. **사용자** > **외부**&#x200B;에서 자체 등록 프로필을 만듭니다. 각 프로필에는 사용자가 등록해야 하는 자체 그룹 ID 및 액세스 키가 있습니다.

## 프로필의 등록 URL 복사

1. **사용자** > **외부**&#x200B;를 선택한 다음 **자가 등록**&#x200B;을 선택합니다.

1. **복사할 랜딩 페이지 URL** 열에서 프로필에 대해 **로그인하지 않음**&#x200B;을 선택합니다.

   ![자체 등록 프로필의 복사할 랜딩 페이지 URL 열](assets/Use-a-non-logged-in-menu-URL-for-self-registration-image1.png "복사할 랜딩 페이지 URL")

1. URL을 복사하고 초대하려는 사용자와 공유합니다.

**복사할 랜딩 페이지 URL** 목록에는 다음 옵션이 포함됩니다.

* **등록**: 표준 등록 URL
* **임시 방문 홈페이지(레거시)**: 임시 방문 홈페이지의 URL입니다.
* **로그인하지 않은 메뉴**: Experience Builder에서 로그인하지 않은 메뉴의 URL

## 사용자가 보는 내용

1. 사용자는 URL을 열고 **브랜딩**&#x200B;에서 선택한 로그인하지 않은 랜딩 페이지에 표시됩니다.

1. 사용자가 **등록**&#x200B;을 선택하고 프로필의 그룹 ID와 액세스 키를 입력합니다.

1. 사용자는 이름, 이메일 주소 및 암호를 입력한 다음 등록을 완료합니다.

Adobe Learning Manager은 URL이 속한 프로필에 사용자를 추가합니다. **사용자** > **외부**&#x200B;에서 해당 프로필의 새 사용자를 볼 수 있습니다.

>[!NOTE]
>
>모든 프로필 URL은 동일한 랜딩 페이지를 표시합니다. 사용자가 추가된 프로필만 다릅니다.

## URL을 사용하여 환영 전자 메일 보내기

1. **사용자** > **외부**&#x200B;를 선택하고 자체 등록 프로필을 선택합니다.

1. **복사할 랜딩 페이지 URL** 목록에서 전자 메일에 포함할 URL을 선택합니다.

   ![메일 및 복사 아이콘이 있는 랜딩 페이지 URL 목록](assets/Use-a-non-logged-in-menu-URL-for-self-registration-image2.png "랜딩 페이지 URL 목록")

1. 전자 메일을 보내려면 메일 아이콘을 선택합니다. 또는 복사 아이콘을 선택하여 URL을 복사합니다.

Adobe Learning Manager에서 **생성된 프로필(외부/파트너)** 템플릿을 사용하여 전자 메일을 보냅니다. 전자 메일에는 선택한 고유 URL, 프로필 인원 제한 및 URL 만료 날짜가 포함됩니다. 초대하려는 사용자와 URL을 공유합니다.

## 기존 로그인하지 않은 홈페이지에서 이동

이 목록의 이전 버전에는 **로그인하지 않음** 옵션이 표시되었습니다. 이제 이름이 **로그인하지 않은 홈페이지(레거시)**&#x200B;로 지정됩니다.

기존의 로그인하지 않은 홈페이지는 향후 릴리스에서 더 이상 사용되지 않을 예정입니다. 이 메뉴를 사용하는 경우 Experience Builder의 로그인하지 않은 메뉴로 이동하여 동일한 기능을 유지합니다.
