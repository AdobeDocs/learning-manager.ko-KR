# 모델 컨텍스트 프로토콜 서버 구성

관리자는 서버를 만들고, 해당 자격 증명을 복사한 다음 연결을 완료하는 AI 클라이언트 관리자에게 제공합니다. 언제든지 서버를 다시 방문하여 편집하고, 도구를 업데이트하고, 자격 증명을 복사하고, 상태를 변경하거나 삭제할 수 있습니다.

## MCP 서버 만들기

1. 관리자 권한으로 Adobe Learning Manager에 로그인합니다.
2. **AI in Learning** \> **MCP 서버**(으)로 이동합니다.
3. **새 MCP 서버**&#x200B;를 선택합니다.
4. 설명을 포함한 서버 세부 정보를 입력합니다.

   * **서버 이름:** 최대 50자의 이름을 입력하십시오.
   * **설명:** 최대 150자의 간단한 설명을 입력하십시오.
   * **URL:** 회사 또는 응용 프로그램 URL을 입력하십시오.
   * **리디렉션 도메인:** 연결할 각 AI 클라이언트의 도메인(예: [http://\*.chatgpt.com](https://encoded-592c9deb-987b-4562-aa3c-9fa3d37d83e9.uri/http%3a%2f%2f*.chatgpt.com) 또는 [http://\*.claude.ai](https://encoded-592c9deb-987b-4562-aa3c-9fa3d37d83e9.uri/http%3a%2f%2f*.claude.ai))을 입력하십시오. 이 필드는 필수입니다.

     ![](/help/migrated/administrators/feature-summary/assets/configure-mcp-admin1.png)

5. **다음**&#x200B;을 선택합니다.
6. **사용 가능한 도구** 페이지에서 서버가 표시하는 학습자 도구를 검토합니다. MCP 도구에 대한 자세한 상황별 설명 및 목적 중심 설명을 제공합니다. 잘 작성된 도구 설명은 MCP 호환 클라이언트가 적절한 도구를 보다 정확하게 발견하고 호출하는 데 도움이 됩니다. 도구의 목적, 지원되는 작업, 예상 입력 및 일반적인 사용 사례를 포함합니다. 명확하고 간결한 설명을 통해 학습자가 AI 도우미와 상호 작용할 때 도구 선택 및 전반적인 사용자 경험이 개선됩니다.

   ![](assets/configure-mcp-admin2.png)

   도구가 선택된 시기 및 도구가 응답하는 방법을 결정하는 지침을 보려면 각 도구에 대해 **보기**&#x200B;를 선택합니다.

   ![](assets/configure-mcp-admin3.png)

7. 왼쪽 탐색 창에서 **클라이언트 자격 증명**&#x200B;을 선택합니다.
8. **MCP 끝점 URL**, **클라이언트 ID** 및 **보안 키**&#x200B;를 복사합니다. 각 값 옆의 **복사**&#x200B;를 선택합니다.

   ![](assets/configure-mcp-admin4.png)

9. **닫기**&#x200B;를 선택합니다.

>[!NOTE]
>
>서버는 학습자 역할을 가진 사용자에게만 읽기 액세스 권한을 제공합니다.

엔드포인트 URL, 클라이언트 ID 및 보안 키를 AI 클라이언트 관리자에게 제공합니다.

## 도구 설명 편집

도구 설명은 AI 클라이언트에게 도구를 선택해야 하는 시기와 도구가 응답하는 방법을 알려 줍니다. 예제 프롬프트를 추가할 수도 있습니다. 잘 작성된 도구 설명은 MCP 호환 클라이언트가 적절한 도구를 보다 정확하게 발견하고 호출하는 데 도움이 됩니다. 도구의 목적, 지원되는 작업, 예상 입력 및 일반적인 사용 사례를 포함합니다.

1. **사용 가능한 도구** 페이지에서 도구에 대한 **작업** 메뉴를 선택합니다.
2. **MCP 도구 구성** \> **편집**&#x200B;을 선택합니다.

   ![](assets/configure-mcp-admin5.png)

3. **도구 편집** 대화 상자에서 **지침/설명**&#x200B;을 업데이트하세요.

   ![](assets/configure-mcp-admin6.png)

4. **예제 프롬프트**&#x200B;에서 프롬프트를 편집합니다. 프롬프트를 추가하려면 **다른 예제 추가**&#x200B;를 선택합니다.
5. **저장**&#x200B;을 선택합니다.

도구를 원래 말로 되돌리려면 도구의 **동작** 메뉴를 선택한 다음 **MCP 도구 구성** \> **재설정**&#x200B;을 선택합니다.

## MCP 서버 편집

1. **Learning의 AI** \> **MCP 서버**&#x200B;를 선택합니다.
2. 서버 이름을 선택합니다.
3. **편집**&#x200B;을 선택합니다.
4. **응용 프로그램 세부 정보** 페이지의 필드를 업데이트한 다음 변경 내용을 저장하십시오.

## MCP 서버 삭제

1. **Learning의 AI** \> **MCP 서버**&#x200B;를 선택합니다.
2. 서버 행에서 **작업** 메뉴를 선택합니다.
3. **삭제**&#x200B;를 선택합니다.
4. 확인 대화 상자에서 **삭제**&#x200B;를 선택합니다.

>[!WARNING]
>
>서버를 삭제하면 연결된 AI 애플리케이션에 대한 모든 도구 액세스 권한이 제거됩니다. 활성 세션은 즉시 작동하지 않을 수 있으며 삭제를 취소할 수 없습니다.

## 문제 해결

**도구 변경 내용이 즉시 표시되지 않습니다.**
도구 설명에 대한 편집이 적용되기까지 어느 정도 시간이 소요됩니다. 기다린 후 다시 시도하십시오.

**서버를 삭제한 후 AI 클라이언트 작동이 중지되었습니다.**
새 서버를 만들고 새 자격 증명을 AI 클라이언트 관리자에게 제공합니다.

**AI 클라이언트가 잘못된 도구를 사용합니다.**
변경한 도구 설명을 검토합니다. **재설정**&#x200B;을 사용하여 원래 단어를 복원합니다.

## 모범 사례

* 특별한 이유가 없으면 원본 도구 설명을 그대로 유지합니다.
* 편집하는 경우 명확하고 구체적인 도구 설명 및 예제 메시지를 작성합니다.
* 비밀 키를 안전하게 저장하고 AI 클라이언트 관리자와 공유합니다.
* 다른 응용 프로그램에 영향을 주지 않고 삭제할 수 있도록 각 AI 응용 프로그램에 대해 별도의 서버를 만듭니다.
* 삭제하기 전에 서버에 종속된 AI 응용 프로그램이 없는지 확인합니다.
