# Virtual Coach 보고서

관리자는 Virtual Coach와 관련된 두 개의 보고서를 볼 수 있습니다. **학습자 사용 요약** 및 **세션 세부 정보**&#x200B;입니다.

![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report1.png)

## 학습자 사용 요약

학습자 사용 요약에는 계정 내에 등록된 모든 학습자의 월별 사용 세부 정보가 포함됩니다. 이러한 사용 세부 정보에는 사용 및 학습 패턴에 대한 통찰력이 포함되어 있습니다.

### 학습자 사용 요약 생성

학습자 사용 요약을 생성하려면 다음을 수행합니다.

1. 관리자로 로그인합니다.
2. **관리** > **보고서** > **AI 보고서**&#x200B;로 이동합니다.
3. **가상 코치** 섹션에서 **학습자 사용 요약**&#x200B;을 선택합니다. **가상 코치 학습자 사용 데이터** 팝업이 나타납니다.
4. **시작 날짜** 및 **종료 날짜**&#x200B;를 선택하세요.
5. **진행**&#x200B;을 선택합니다. 보고서는 .csv 파일로 생성됩니다. 파일 탐색기의 **다운로드** 폴더에서 다운로드한 .csv 파일을 찾을 수 있습니다.

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report2.png)

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report-learn-usage-6.png)

## 세션 세부 정보

**세션 세부 정보** 보고서에는 지난 90일 동안 계정 내에 등록된 모든 학습자의 세션 세부 정보가 포함됩니다. 이러한 사용 세부 정보에는 사용 및 학습 패턴에 대한 통찰력이 포함되어 있습니다.

### 세션 세부 정보 생성

세션 세부 정보 보고서를 생성하려면 다음을 수행하십시오.

1. 관리자로 로그인합니다.
1. **관리** > **보고서** > **AI 보고서**&#x200B;로 이동합니다.
1. **가상 코치** 섹션에서 **세션 세부 정보**&#x200B;를 선택합니다. **보고서 요청 생성** 팝업이 나타납니다.
1. **확인**&#x200B;을 선택합니다. 보고서는 .csv 파일로 생성됩니다. 파일 탐색기의 **다운로드** 폴더에서 다운로드한 .csv 파일을 찾을 수 있습니다.

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report3.png)

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report-session-4.png)

>[!NOTE]
>
>Adobe Learning Manager은 학습자의 가상 코치 세션 기록을 보관하지 않습니다. 학습자는 여러 세션을 수강할 수 있습니다. 그러나 학습자는 이전 가상 코치 세션으로 돌아갈 수 없습니다.
