# 관리자 브랜딩: 홈페이지 PLP 및 VC 스트립 재배치

## Adobe Learning Manager에서 홈페이지 스트립 추가 및 재정렬

개인화된 학습 경로 및 가상 코치 스트립을 학습자 홈페이지에 추가하고, 스트립을 드래그하여 학습자가 볼 수 있는 순서를 설정합니다.

책임자는 Adobe Learning Manager의 학습자 홈페이지에 개인화된 학습 경로(PLP)와 가상 코치 스트립을 추가할 수 있습니다. **관리자 브랜딩**&#x200B;에서 끌어서 놓기 컨트롤을 사용하여 모든 홈페이지 스트립의 순서를 변경할 수도 있습니다. 이제 학습자가 먼저 볼 스트립을 결정할 수 있습니다.

사용자 정의 페이지에 개인화된 학습 경로 위젯을 추가할 수도 있습니다.

### 홈페이지 스트립 정보

홈페이지 스트립은 학습자 홈페이지에 나타나는 위젯(카드)입니다. 관리자 브랜딩에서는 스트립의 표시 순서 및 스트립의 표시 순서를 제어합니다. ALM의 2026년 12월 릴리스에서는 두 개의 AI 기반 스트립을 사용할 수 있습니다.

* **개인 맞춤화된 학습 경로 스트립:** 각 학습자의 AI 생성 학습 경로를 강조합니다.
* **가상 코치 스트립:** 학습자가 홈페이지에서 코치 경험을 찾고 여는 데 도움이 됩니다.

### 개인화된 학습 경로 스트립

학습자는 스트립을 사용하여 다음과 같은 작업을 수행할 수 있습니다.

* AI 생성 학습 경로에 액세스합니다.
* 이전에 생성한 학습 경로를 계속 진행합니다.
* 추천 학습 여정을 살펴보십시오.

### 가상 코치 스트립

학습자는 스트립을 사용하여 다음과 같은 작업을 수행할 수 있습니다.

* Virtual Coach 환경을 살펴봅니다.
* 코칭 활동을 재개합니다.
* 홈페이지에서 대화식 AI 코칭을 시작합니다.

### 홈페이지 스트립 재정렬

원하는 위치에 아무 스트립이나 배치할 수 있습니다. 예를 들어, 먼저 가상 코치 스트립을 표시한 다음 개인 맞춤화된 학습 경로, **권장**, **카탈로그** 스트립, **최근 보기**&#x200B;를 표시할 수 있습니다.

1. 관리자 앱의 왼쪽 탐색 창에서 **구성** > **브랜딩**&#x200B;을 선택합니다.

   ![](assets/admin-branding5.png)

2. **학습자 홈페이지**&#x200B;를 선택합니다.
3. 스트립 목록에서 이동할 스트립을 찾습니다.
4. 스트립을 새 위치로 드래그합니다.

   ![](assets/admin-branding1.png)

5. 변경 사항을 저장합니다.

게시하면 새 순서가 학습자 홈페이지에 표시됩니다.

>[!NOTE]
>
>맞춤화된 학습 경로 또는 가상 코치 스트립이 목록에 없으면 순서를 바꾸기 전에 홈페이지 구성에 추가되었는지 확인하십시오.

## 사용자 정의 페이지에 개인화된 학습 경로 위젯 추가

홈페이지 외부에서 개인화된 학습 경로 위젯을 사용할 수 있습니다. 사용자 정의 페이지에 추가하여 학습자가 개인화된 학습 권장 사항을 찾을 수 있는 전용 위치를 제공합니다.

1. **사용자 지정 페이지**&#x200B;를 선택합니다.
2. 페이지를 만들거나 기존 페이지를 편집합니다.
3. **개인 설정된 학습 경로** 위젯을 추가합니다.

   ![](assets/admin-branding2.png)

   위젯을 검토합니다.

   ![](assets/admin-branding3.png)

4. **진행**&#x200B;을 선택합니다.
5. 위젯 제목 및 설명을 추가합니다.

   ![](assets/admin-branding4.png)

6. **위젯 추가**&#x200B;를 선택합니다.
7. 페이지를 저장 합니다.
8. Publish 페이지
