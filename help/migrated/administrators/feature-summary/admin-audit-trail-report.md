# 관리자 감사 추적 보고서 {#adminaudittrailreport}

계정의 기본, 고급 및 통합 설정에 대한 구성 변경 내용(각 변경 내용, 변경 시기 및 이전/이후 값 포함)에 대한 보고서를 생성합니다.

## 보고서가 캡처하는 내용

관리자 감사 추적 보고서는 구성 변경 기록 레코드를 제공하므로 다음을 확인할 수 있습니다.

- 변경 사항 적용 대상
- 변경이 이루어진 시기
- 변경 전의 설정
- 변경 후의 설정

이 보고서는 다음과 같은 변경 사항을 다룹니다.

- **기본** 설정
- **고급** 설정
- **통합** 설정

이 보고서는 추가 전용입니다. 새 변경 레코드는 시간에 따라 추가되며 이전에 기록된 항목은 제거되지 않습니다. 그러면 현재 값뿐만 아니라 여러 변경 사항에 걸쳐 전체 설정 기록을 검토할 수 있습니다.

보고서는 보고서 권한 및 전체 사용자 그룹 액세스 권한이 있는 모든 사용자가 사용할 수 있습니다. 여기에는 보고서 액세스 권한이 부여된 전체 관리자 및 사용자 정의 관리자가 포함됩니다.

>[!NOTE]
>
>업데이트 112, 2026년 9월부터 레코드를 사용할 수 있습니다. 이 업데이트 이전에 변경한 내용은 보고서에 포함되지 않습니다. [릴리스 정보](/help/migrated/release-note/release-notes.md) 업데이트 112를 참조하십시오.

## 이 보고서가 규정 준수에 중요한 이유

규제 대상 업종을 운영하는 조직은 전자 기록을 처리하는 시스템의 구성 변경이 추적, 귀속 및 보존된다는 것을 입증해야 하는 경우가 많습니다. 관리자 감사 추적 보고서는 각 변경 사항에 대한 개인, 설정, 시간 및 전후 값을 식별하여 이러한 요구 사항을 지원합니다.

>[!NOTE]
>
>이 보고서는 조직의 규정 준수 활동을 지원합니다. 그 자체로 어떤 특정 규정이나 표준을 준수하고 있다는 것을 증명하지 않는다.

## 관리자 감사 추적 보고서 생성

1. 관리자로 Adobe Learning Manager에 로그인합니다.
2. 왼쪽 탐색에서 **관리** > **보고서** > **사용자 지정 보고서**&#x200B;를 선택합니다.

   ![](/help/migrated/administrators/feature-summary/assets/audit-trail-report1.png)

3. 아래로 스크롤하고 **관리자 감사 추적**&#x200B;을 선택합니다.

   ![](/help/migrated/administrators/feature-summary/assets/audit-trail-report2.png)

4. **범위 선택**: 보고할 기간 선택 — **최근 1주**, **최근 1개월** 또는 **날짜 선택**. **날짜 선택**&#x200B;을 선택하는 경우 **시작** 날짜와 **종료** 날짜를 입력하십시오.
5. **설정 유형 선택**: **모두 선택**, **기본 사항**, **통합** 또는 **고급**&#x200B;을 선택합니다.

   기본, 통합 및 고급 전체에서 이 보고서에서 추적한 전체 설정 목록을 보려면 **설정 목록 다운로드**&#x200B;를 선택하세요.

   ![](/help/migrated/administrators/feature-summary/assets/audit-trail-report6.png)

   ![](/help/migrated/administrators/feature-summary/assets/audit-trail-report3.png)

6. **생성**&#x200B;을 선택합니다.

   ![](/help/migrated/administrators/feature-summary/assets/audit-trail-report4.png)

   ![](/help/migrated/administrators/feature-summary/assets/audit-trail-report5.png)

변경 사항이 포함된 `.csv` 파일이 브라우저의 다운로드 폴더에 다운로드됩니다. 보고서 생성이 완료되기까지 몇 분 정도 소요될 수 있습니다. 처리되는 동안 Adobe Learning Manager을 계속 사용할 수 있습니다. 보고서가 준비되기 전에 브라우저 창을 닫으면, 다음에 로그인할 때 다운로드가 시작됩니다.

## 이 보고서의 일반적인 사용

- **예기치 않은 설정 변경을 조사합니다** — 가정에 의존하지 않고 변경된 내용, 변경 시기 및 변경 주체를 확인합니다.
- **여러 관리자가 변경한 내용 검토** - 각 관리자에게 개별적으로 연락하는 대신 지정된 기간 동안 보고서 범위에 있는 모든 구성 작업의 통합 보기를 생성합니다.
- **승인된 구성 변경 확인** - 예상 관리자가 예상 기간 내에 변경했으며 새 값이 승인된 값과 일치하는지 확인합니다.
- **여러 변경 내용에 대한 설정 기록 비교** — **수정** 열을 사용하여 특정 설정이 얼마나 변경되었는지 확인하고 이후의 변경 내용이 이전 값을 복원했는지 여부를 포함하여 기록된 각 값을 차례로 검토합니다.
- **준수 검토 지원** - 관리 및 준수 기록의 일부로 검토 중인 기간 동안 보고서를 생성합니다.
- **정책 변경 후 설정 검토** — 의도한 구성 업데이트가 일관되게 적용되었는지 확인하고 예기치 않게 발생한 변경 내용을 확인합니다.
- **기록 관리 기록 유지** - 조직의 기록 관리 관행에 따라 보고서를 다운로드하고 유지합니다.

## 보고서 열 참조

다운로드한 `.csv` 파일에는 다음 열이 포함되어 있습니다.

| 열 | 설명 |
|---|---|
| **이벤트 ID** | 이 특정 변경 레코드의 고유 식별자. |
| **타임스탬프(UTC)** | 변경 날짜와 시간(협정 세계시)입니다. |
| **전자 메일** | 변경한 관리자의 이메일 주소입니다. |
| **UUID** | 변경한 관리자의 고유 식별자. UUID가 계정 수준에서 활성화된 경우에만 채워집니다. |
| **관리자 이름** | 변경한 관리자의 표시 이름입니다. |
| **이벤트 유형** | 기록된 이벤트의 범주(예: `Modify`, `Create` 또는 `Delete`)입니다. |
| **작업 유형** | 설정에 대해 수행된 작업의 유형(예: `CREATE_SETTING`, `UPDATE_SETTING` 또는 `DELETE_SETTING`)입니다. |
| **개체 유형** | 변경된 설정 또는 구성 개체입니다. |
| **개체 ID** | 변경된 특정 설정 또는 구성 개체의 고유 식별자 |
| **이전 값** | 변경 전의 설정 값입니다. 삭제된 설정의 경우, 이 옵션은 삭제 전에 존재했던 값을 표시합니다. |
| **새 값** | 변경 후의 설정 값입니다. (삭제된 설정의 경우 이 옵션은 비어 있습니다.) |
| **수정** | 이벤트가 기록될 때 이 특정 개체 ID가 변경된 횟수입니다. 개체에 대한 첫 번째 기록된 변경 사항은 1부터 시작됩니다. |

>[!TIP]
>
>기간 동안 삭제된 모든 설정을 찾으려면 **작업 유형**&#x200B;이 `DELETE_SETTING`인 다운로드한 파일을 필터링하세요.

## 프로그래밍 방식으로 이 보고서에 액세스

관리자 앱에서 수동으로 생성하지 않고 작업 API를 사용하여 프로그래밍 방식으로 관리자 감사 추적 보고서를 검색할 수 있습니다. 이 기능은 정기 내보내기를 예약하거나 다운스트림 모니터링 또는 경고 시스템으로 보고서를 제공할 때 유용합니다. [작업 API 관리자 감사 추적 보고서](/help/migrated/api-changes-sep-2026.md#job-api-for-admin-audit-trail-report)를 참조하세요.

## 제한 사항

- **지역화**: 보고서 콘텐츠가 지역화되지 않았습니다. 보고서는 계정의 구성된 로케일 설정과 관계없이 기본 계정 언어로 생성됩니다.
- **변경 이유**: 보고서는 변경 이유를 캡처하지 않습니다. 관련된 변경 요청, 승인 또는 비즈니스 근거를 별도로 유지합니다.

## 모범 사례

- 의심되는 변경 또는 계획된 변경 사항을 포함하는 날짜 범위를 선택합니다.
- 영향을 받는 설정 영역을 알 수 없는 경우 **모두 선택**&#x200B;을 선택합니다.
- 각 항목의 **이전 값** 및 **새 값** 열을 모두 비교합니다.
- **관리자 이름** 및 **타임스탬프** 열을 사용하여 변경 내용을 승인된 작업 또는 내부 레코드와 상관시킵니다.
- 조직에서 변경에 대해 문서화된 설명을 필요로 하는 경우 관련 변경 요청, 승인 또는 비즈니스 근거를 별도로 보관하십시오.

## 문제 해결

**특정 날짜 이전에는 레코드가 표시되지 않음**
업데이트 112(2026년 9월) 이후에만 레코드를 사용할 수 있습니다. 해당 업데이트 이전에 변경한 내용은 보고서에 포함되지 않습니다. [릴리스 정보](/help/migrated/release-note/release-notes.md) 보기

**일부 또는 모든 레코드의 UUID 열이 비어 있습니다.**
UUID 열은 UUID가 계정 수준에서 활성화된 경우에만 채워집니다. 활성화되지 않은 경우 이 열은 표시되지 않습니다.

**사용자 지정 관리자 역할이 있지만 이 보고서를 찾을 수 없습니다.**
사용자 정의 역할에 보고서 권한 및 전체 사용자 그룹 액세스 권한이 부여되었는지 확인합니다. 필요한 경우 계정 소유자 또는 전체 관리자에게 문의하여 이 액세스 권한을 요청하십시오.
