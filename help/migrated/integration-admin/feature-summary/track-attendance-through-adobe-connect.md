# Adobe Connect 기록 보기를 통해 출석 추적

## 개요

Adobe Learning Manager은 기록 보기를 통해 Adobe Connect 가상 강의실 세션의 출석을 추적할 수 있습니다. 학습자가 라이브 세션을 놓쳤지만 Adobe Connect에서 충분히 오랫동안 녹음을 시청하면 Learning Manager는 학습자를 세션에 참석한 것으로 표시합니다. 그런 다음 학습자는 세션 모듈을 완료하고 세션이 속한 학습 개체를 완료하는 방향으로 이동할 수 있습니다.

이 기능 이전에는 Learning Manager에서 Connect 녹음을 시청한 학습자의 출석을 기록할 수 있는 방법이 없었습니다. 라이브 세션을 놓친 학습자는 라이브 세션을 완료할 수 없으며, 강사가 직접 개입하여 출석을 표시해야 했습니다. 이 기능은 해당 수동 단계를 제거합니다. Adobe Connect은 어떤 녹화를 얼마나 오래 시청했는지 보고하며, Learning Manager는 시청 시간을 계정에 대해 설정된 완료 기준과 비교합니다.

학습자가 녹화된 세션의 완료 기준을 충족하면 책임자 앱에서 학습자가 표시됩니다.

Adobe Learning Manager이 동일한 이메일 ID를 사용하여 학습자를 Adobe Connect으로 리디렉션하므로 학습자의 이메일 ID는 Adobe Learning Manager과 Adobe Connect에서 동일해야 합니다.
기본 동기화 빈도와 통합 책임자가 설정할 수 있는 최단 간격은 1시간입니다.


## 누가 무엇을 하나요

| 역할 | 기능 |
|----------------------------|-----------------------------------------------------------------------------------------------------------------------|
| Prime에서 | 세션 기록을 열고 라이브 세션이 누락된 후 확인합니다. |
| 강사 | 라이브 세션 중에 기록을 시작하여 기록과 대본이 존재합니다. |
| 통합 책임자 | 출석 동기화가 사용하는 Adobe Connect 계정을 구성하고, 동기화 일정을 설정하거나 설정 또는 해제합니다. |
| 작성자 또는 배달 관리자 | 가상 강의실 세션을 예약한 다음 여러 날 프로그램에 대해 지속 회의실을 다시 사용합니다. |
| Adobe Connect | 각 학습자의 전자 메일과 녹화 시청 시간을 캡처하고 API를 통해 녹화 뷰어 목록을 표시합니다. |

각 역할은 레코딩 방식의 출결업무를 만드는 별도의 부분이 있다.

| 완료 조건 | 학습자가 모듈에 대해 완료로 표시되어야 하는 기록 백분율입니다. |

## 사용 사례

### 학습자가 라이브 세션을 놓칩니다.

학습자는 라이브 가상 강의실 세션에 참여할 수 없습니다. 나중에 학습자는 Learning Manager에서 세션을 열고 기록을 확인합니다. 시청 시간이 완료 기준을 충족하면 Learning Manager에서 학습자를 출석으로 표시하고 학습자는 강사에게 도움을 요청하지 않고 모듈을 완료합니다.

### 일부만 시청하는 학습자

학습자가 레코딩을 열지만 필요한 공유 횟수보다 적게 봅니다. 완료 조건이 충족되지 않아 Learning Manager에서 학습자를 출석으로 표시하지 않습니다.

### 하나의 지속 회의실에서 여러 날 세션

작성자 또는 전달 관리자는 동일한 지속 Connect 회의실에서 1일, 2일 및 3일의 세션을 예약합니다. Adobe Connect에 로그인하지 않고도 회의실 이름을 보고 다시 사용할 수 있습니다.

| Connect에서 시청 시간 | Adobe Connect이 캡처한 학습자 전자 메일 및 기록 시청 시간을 사용합니다. |
| 완료 기준 임계값 | 시청 시간이 완료 기준에 설정된 백분율에 도달하면 학습자가 모듈에 대해 완료 표시를 합니다. |
| 실제 시청 시간만 | 학습자가 실제로 본 시간을 계산합니다. 검색 막대를 드래그해도 시청 시간이 추가되지 않습니다. |
| 예약된 동기화 | 통합 관리자가 제어하는 일정에서 백엔드 파이프라인을 실행하며 설정하거나 해제할 수 있습니다. |
| 지속 회의실 가시성 | 작성자가 며칠 동안 지속 회의실을 재사용할 수 있도록 인스턴스 레벨에서 회의실 연결 이름을 표시합니다. |

## 출석 추적 작동 방식

*기록을 여는 학습자가 Learning Manager에 모듈을 완료로 표시합니다.*

### 엔드투엔드 플로우

1. 강사가 Adobe Connect에서 라이브 가상 강의실 세션을 진행하고 녹화를 시작합니다. 녹화와 대본은 세션이 끝난 후 사용할 수 있습니다.

1. 세션을 놓친 학습자가 기록을 선택하여 확인합니다. Adobe Connect은 보기를 자동으로 추적합니다.

1. Adobe Connect은 학습자의 전자 메일과 학습자가 실제로 시청한 시간을 캡처합니다.

1. 구성된 일정에서 백엔드 SnapLogic 파이프라인은 Adobe Connect API를 호출하고 지정된 시간 프레임 동안 기록 뷰어 목록을 가져옵니다. 파이프라인은 통합 책임자에 설정된 Adobe Connect 계정을 사용합니다.

1. Learning Manager는 각 뷰어를 일치하는 강의 및 모듈에 매핑합니다.

1. Learning Manager는 학습자의 총 시청 시간과 완료 기준을 비교합니다.

1. 시청 시간이 기준을 충족하면 Learning Manager에서 학습자가 모듈에 대해 완료 표시를 합니다. 백엔드에서 Learning Manager는 사용자 강의 등급 CSV를 입력하여 기록합니다.

>[!NOTE]
>
>Adobe Connect은 Learning Manager에 데이터를 푸시하지 않습니다. Learning Manager는 Adobe Connect 인스턴스 레벨에서 이를 가져옵니다. 예를 들어 &quot;이 다섯 명의 사용자는 지난 24시간 동안 이 여섯 개의 녹음을 시청했습니다.&quot; 따라서 출석은 학습자가 시청을 완료하는 순간이 아니라 다음 파이프라인 실행 후에 업데이트됩니다.

### 완료 조건 및 시청 시간

학습자는 이수 기준이 정의하는 기록 비율 이상을 확인해야 합니다. 다음 규칙에 유의하십시오.

* 백분율은 예약된 세션 기간이 아닌 기록 기간에 적용됩니다. 15분 세션이 5분 동안만 기록되는 경우 필요한 시간은 5분을 기준으로 합니다. Adobe Connect에서 기록 지속 시간을 제공합니다.

* 백분율은 Learning Manager 쪽에 설정됩니다. 이는 계정 전체에서 공통적인 설정이며 각 인스턴스에 대한 설정은 아닙니다. 라이브 세션에 이미 적용된 동일한 유형의 설정(예: 80% 참가 필요)

* Adobe Connect은 학습자가 실제로 얼마나 오래 시청했는지 기록합니다. 검색 막대로 건너뛰어도 소용이 없으며, Learning Manager에서는 Connect가 통과하는 시청 시간을 처리합니다.

| 완료 조건 | 녹음 길이 | 시청 시간 필요 | 결과 |
|-------------------------|------------------------------------|-----------------------|-------------------------------------------------------------|
| 50% | 5분 | 2.5분 | 2.5분이 지나면 완료로 표시됨 |
| 50% | 5분(세션은 15분임) | 2.5분 | 15분 세션이 아닌 5분 녹음을 기준으로 합니다. |
| 0% | 모두 | 여는 것 이상 없음 | 레코딩을 여는 것만으로도 충분합니다. |

### 자격 창

Learning Manager는 학습 객체의 완료 날짜까지의 기록 기반 출석만 적용합니다. 학습 개체에 완료 날짜가 없으면 Learning Manager는 상위 학습 개체의 완료 날짜를 사용합니다.

### 동기화 예약

통합 책임자는 파이프라인이 실행되는 빈도를 제어합니다. 일정은 시간별 또는 주별(기타 간격)로 지정할 수 있으며 통합 책임자는 일정을 설정하거나 해제할 수 있습니다. 모든 실행에 동일한 Adobe Connect 계정이 사용됩니다.

### 변경 사항

* 사용자가 1일째 생성된 지속 회의실을 추가하면 Learning Manager에서 해당 회의실에 대한 액세스 권한을 부여합니다. 그런 다음 다른 요일에 세션에 같은 회의실을 추가할 수 있습니다.
* Learning Manager는 **가상 강의실 URL** 옆의 세션 세부 정보에 인스턴스 수준의 Connect 회의실 이름을 표시합니다.
* 기본 인스턴스의 경우 Learning Manager는 강의 생성 중에 설정된 회의실을 표시합니다.

### 제한 사항 및 고려 사항

* Learning Manager는 일정에 따라 데이터를 가져오기 때문에 출석이 실시간으로 이루어지지 않습니다.
* 이 기능은 Connect 기반 가상 강의실 세션에만 적용됩니다.
* 기록이 있어야 강사가 라이브 세션 중에 기록을 시작해야 합니다.
* 학습자는 Adobe Connect에서 캡처한 전자 메일 주소를 통해 일치합니다.
* 검색 막대를 드래그해도 시청 시간이 추가되지 않습니다.
* 레코딩 기반 출석은 학습 개체 또는 상위 학습 개체의 완료 날짜에서 중지됩니다.

### 유의 사항

* 시청 시간은 지정된 백분율보다 크거나 같아야 합니다(예: 5분의 50%는 2.5분). 학습자가 세션을 반복적으로 시청 중인 경우 시청 시간이 합산되지 않지만 지정된 시청 시간에는 미치지 않습니다. 단, 시청 시간은 학습자가 특정 시점에 세션을 보고 임계값 기준을 충족하더라도 합산됩니다. 예를 들어 학습자가 1일 차 세션에서 1분을 지켜본 다음, 자신이 퇴사한 시점에서 다음 날 세션의 1.5분을 더 지켜보면 시청 시간이 더해집니다. 이 문제는 Adobe Connect 측에서 발생합니다.

* 완료 조건은 강의 레벨 및 계정 레벨에서 구성할 수 있습니다. 라이브 세션 참여와 효과가 동일합니다.

* 기본 동기화 빈도와 통합 책임자가 설정할 수 있는 최단 간격은 1시간입니다.

* Adobe Learning Manager이 동일한 이메일 ID를 사용하여 학습자를 Adobe Connect으로 리디렉션하므로 학습자의 이메일 ID는 Adobe Learning Manager과 Adobe Connect에서 동일해야 합니다.

### FAQ

**Q. 학습자가 라이브 세션에 참석해야 합니까?**
**A.** 아니요. 라이브 세션을 놓친 학습자는 충분히 오랫동안 녹음/녹화를 보면서 참석함으로 표시할 수 있습니다.

**Q. 학습자는 얼마나 많은 녹음/녹화를 시청해야 합니까?**
**A.** 완료 조건의 백분율로, 기록 지속 시간에 적용됩니다. 예를 들어 50%일 때 5분 녹화를 하려면 적어도 2.5분의 시청 시간이 필요합니다.

**Q. 레코딩 수에서 앞으로 건너뛰시겠습니까?**
**A.** 아니요. Adobe Connect은 학습자가 실제로 본 시간을 기록하므로 검색 막대를 드래그하는 것은 계산에 포함되지 않습니다.

**Q. 학습자가 시청을 마치면 바로 출석으로 표시됩니까?**
**A.** 아니요. Learning Manager는 일정대로 Adobe Connect에서 뷰어 데이터를 가져와 다음 파이프라인 실행 후 출석을 업데이트합니다.

**Q. Adobe Connect에서 데이터를 Learning Manager로 전송합니까?**
**A.** 아니요. Learning Manager에서 가져오기. 이는 푸시가 아닌 Adobe Connect 인스턴스 레벨의 끌어오기 메커니즘입니다.

**Q. Learning Manager는 어떤 학습자가 시청했는지 어떻게 알 수 있습니까?**
**A.** Adobe Connect은 학습자의 전자 메일과 녹화 시청 시간을 캡처합니다. Learning Manager는 강의 및 모듈에 매핑합니다.

**Q. 동기화 실행 빈도는 누가 제어합니까?**
**A.** 통합 책임자는 일정을 설정하며 해당 일정을 켜거나 끌 수 있습니다.

**Q. 각 인스턴스에 완료율이 설정되어 있습니까?**
**A.** 아니요. 이는 계정 전체에 공통적으로 적용되는 설정입니다.

**Q. 다일 세션을 통해 하나의 Connect 회의실을 공유할 수 있습니까?**
**A.** 예. 작성자는 1일 동안 생성된 지속 회의실을 다른 일 동안 세션에서 재사용할 수 있으며 회의실 이름은 Learning Manager의 인스턴스 레벨에서 나타납니다.
