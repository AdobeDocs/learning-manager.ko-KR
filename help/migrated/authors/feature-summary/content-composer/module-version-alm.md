# Adobe Learning Manager의 모듈 버전 관리

시간이 지남에 따라 소스 자료 변경 - 정책이 개정되고, SOP가 새로운 버전을 받고, 피치 데크가 업데이트됩니다. 콘텐츠 컴포저 및 ALM은 원본 위치 편집이 아닌 버전 변경으로 새로 고침을 처리하므로 이전에 게시된 강의는 기본 모듈을 업데이트하는 동안 계속 작동합니다.

다시 게시하면 Adobe Learning Manager이 기존 모듈을 콘텐츠 라이브러리에 새 버전으로 업로드하여 모듈의 버전 번호를 1씩 증가시킵니다.

1. Content Composer에서 소스 파일을 업데이트하고 영향을 받는 레슨을 다시 생성합니다(소스 자료가 변경될 때 강의 업데이트 참조). 그런 다음 다시 게시합니다.

2. 업데이트를 게시해도 기존 모듈이 덮어써지지 않으며, ALM 콘텐츠 라이브러리에 새 버전이 함께 추가됩니다.

3. ALM 작성자는 모듈을 사용하여 새 버전을 가리키는 각 ALM 강의를 명시적으로 업데이트해야 합니다. 기존 강의는 ALM 작성자가 변경하기 전까지 구축된 버전을 계속 참조합니다.

4. 이전 버전에서 이미 강의를 완료한 학습자는 기존 완료 기록을 유지합니다. 새 버전은 ALM 강의가 업데이트된 후 등록된 학습자에게 적용됩니다.

다시 게시하기 전에 콘텐츠 컴포저에서 재생성된 레슨을 검토합니다. 재생성 을 통해 영향을 받는 단원에서 이전에 편집한 텍스트, 이미지 또는 퀴즈 질문을 조정할 수 있습니다.
