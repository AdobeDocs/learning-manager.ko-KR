# 테마 적용

강의 테마는 전체 강의의 글꼴, 색상, 머리글, 바닥글 및 구성 요소 스타일을 제어합니다.

커스터마이징 작업 없이 테마를 적용하여 빠르고 세련되며 일관성 있는 룩을 연출할 수 있습니다.

1. 도구 모음에서 **테마**&#x200B;를 선택합니다. **과정 테마** 패널이 열리고 사용 가능한 모든 테마가 표시됩니다.
   ![](../assets/34_course_themes_panel_open_updated.png)

2. 사용 가능한 테마를 찾아보십시오.

   1. **기본값:**&#x200B;은 Content Composer와 함께 제공되는 기본 테마를 표시합니다.

   2. **사용자 지정:**&#x200B;은 사용자가 만들고 저장한 테마를 표시합니다.

   3. **검색** 막대를 사용하여 이름으로 테마를 찾습니다.

3. 적용할 테마를 선택합니다. 강의 미리 보기가 자동으로 업데이트됩니다.
