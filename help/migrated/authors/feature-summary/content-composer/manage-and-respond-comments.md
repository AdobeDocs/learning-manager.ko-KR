# 주석 관리 및 응답

작성자는 프로젝트의 **주석** 패널을 사용하여 주석을 보고 회신할 수 있습니다.

1. 상단 도구 모음에서 **주석**&#x200B;을 선택합니다. 모든 검토자 주석을 표시하는 **주석** 패널이 열립니다.

   ![](../assets/63_owner_in_app_comments_panel_mention_comment.png)

2. 주석을 선택하여 캔버스에서 컨텍스트에서 확인합니다.

   ![](../assets/64_comment_in_context_on_canvas.png)

3. 확인 표시 아이콘을 선택하여 댓글을 해결됨으로 표시하거나 **기타 옵션** 아이콘을 선택하여 편집하거나 삭제합니다.

   ![](../assets/65_comment_resolve_checkmark_delete_menu.png)

4. 업데이트된 과정을 저장합니다.

5. 검토자가 최신 버전을 볼 수 있도록 검토 링크를 업데이트하려면 **공유**&#x200B;를 선택합니다.
