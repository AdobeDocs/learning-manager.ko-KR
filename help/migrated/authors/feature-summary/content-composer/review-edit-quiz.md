# 퀴즈 검토 및 편집

![](../assets/12_quiz_block_question_view_updated.png)

강의 끝에 점수를 매긴 퀴즈가 나타납니다. 각 질문에는 테스트하는 주제 태그가 지정됩니다.

>[!NOTE]
>
>레슨에 포함된 지식 검사는 점수를 매기지 않습니다. 수업 종료 퀴즈만 점수를 매깁니다.


질문을 편집하려면 다음을 수행하십시오.

1. 질문 텍스트를 선택하여 편집하고 텍스트 편집 옵션을 사용하여 스타일을 조정합니다.
   ![](../assets/13_quiz_question_text_edit_toolbar_updated.png)

2. 올바르게 표시하려는 옵션 옆의 라디오 버튼을 선택합니다.

3. 정답에 점수를 할당할 수도 있습니다.
   ![](../assets/14_quiz_question_options_scoring_panel_updated.png)

4. 질문을 삭제하려면 **옵션 제거**&#x200B;를 선택하세요.

5. 질문을 다시 생성하려면 조수에게 &quot;1과에서 퀴즈를 다시 생성합니다.&quot;라고 물어보십시오.
