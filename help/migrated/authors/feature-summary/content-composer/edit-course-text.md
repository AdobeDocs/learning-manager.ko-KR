# 강의 텍스트 편집

![](../assets/15_lesson_image_text_block_fall_prevention_updated.png)

텍스트 요소를 선택하여 그 안에 커서를 놓습니다. 캔버스 맨 아래에 굵게, 기울임꼴, 밑줄, 취소선, 링크, 정렬, 목록 컨트롤이 있는 서식 도구 모음이 표시됩니다.

>[!NOTE]
>
>주제 이름과 강의 이름은 개요 구조의 일부입니다. 강의를 생성한 후 이름을 바꾸려면 조수에게 &quot;2과 이름을 &#39;암호 위생&#39;으로 바꾸십시오.&quot;라고 요청하십시오. 강의 편집기에서 제목을 선택하여 이름을 변경할 수 없습니다.
