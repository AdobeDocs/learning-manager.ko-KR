# Adobe Learning Manager Content Composer 베타 제한 사항

현재 Content Composer Beta 제약 조건의 전체 목록과 설명 및 해결 방법(있는 경우)입니다.

## 현재 제한 사항

다음 표에서는 현재 베타 릴리스의 알려진 모든 제약 조건을 설명합니다.

| **제한** | **설명** | **해결 방법** |
|---------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **윤곽선 편집은 대화용으로만 사용** | 캔버스에서 강의나 주제를 선택하여 이름을 바꾸거나 순서를 바꾸거나 삭제할 수 없습니다. 모든 개요 변경은 도우미 채팅 패널을 통해 이루어져야 합니다. | 조수에게 물어보십시오. &quot;2과 이름을 &#39;암호 위생&#39;으로 바꾸십시오.&quot; 또는 &quot;1.3과 2로 주제를 이동하십시오.&quot; |
| **윤곽선 계층 구조가 수정되었습니다** | 강의 구조는 강의 > 주제에서 수정되었습니다. 하위 항목, 추가 계층 레벨 또는 사용자 정의 구조는 만들 수 없습니다. | 사용 가능한 구성 요소를 사용하여 주제 내에 깊이를 추가합니다. |
| **강의 생성 후에는 윤곽선을 직접 편집할 수 없습니다.** | 강의가 생성되면 주제 이름과 강의 이름은 개요 구조의 일부로 유지됩니다. 개요를 변경하려면 개요 수준의 대화로 돌아가야 합니다. 강의 편집기에서 제목을 선택하여 이름을 변경할 수 없습니다. | 강의 편집기의 도우미에게 다음과 같이 질문합니다. &quot;3과의 이름을 &#39;사고 응답&#39;으로 바꿉니다.&quot; |
| **평가 유형: MCQ 및 참/거짓 전용** | 현재 베타는 객관식 질문(**MCQ**) 및 참/거짓 질문만 지원합니다. 다른 평가 유형을 사용할 수 없습니다. | - |
| **문제 은행을 사용할 수 없음** | 미리 작성된 질문의 은행은 가져오거나 관리할 수 없습니다. | 대화형으로 추가 질문 구성: &quot;1단원 퀴즈에 질문 두 개 더 추가합니다.&quot; |
| **지식 검사가 점수를 매기지 않음** | 레슨에 포함된 지식 검사는 점수를 매기지 않습니다. 수업이 끝난 퀴즈 평가만 등급이 매겨지고 기록됩니다. | 완료 또는 점수 기록을 생성해야 하는 모든 평가에 대해 퀴즈(지식 검사 아님)를 사용합니다. |
| **지원되는 기능으로 제한된 대화 동작** | 보조 관리자가 자유롭게 토론하고 브레인스토밍할 수 있지만 실제 과정 수정은 제품에서 지원하는 기능으로 제한됩니다. 지원되지 않는 콘텐츠 구조나 형식을 생성하는 요청은 실패할 수 있습니다. | 요청이 작동하지 않으면 도우미에게 대신 수행할 수 있는 작업을 설명합니다. |
| **문서 제한 생성** | **출력을 파일의 콘텐츠로 제한**&#x200B;이(가) 활성화되면 콘텐츠 컴포저는 업로드된 소스 문서에서만 콘텐츠를 생성합니다. 그러한 정보원 이외의 정보는 도입하지 않는다. | 토글을 비활성화하여 AI가 일반 지식을 보완하도록 합니다. |
| **공동 작업 기능이 발전하고 있습니다** | 검토용으로 공유와 학습자용 주석 달기 및 공유 기능은 모두 현재 개발 중입니다. GA 전에 구축 세부 정보가 변경될 수 있습니다. | **링크 복사**&#x200B;를 사용하여 비공식 검토를 위해 미리 보기 링크를 공유합니다. 공동 편집의 경우 공동 작업자와 회전을 조정할 수 있습니다. 동시 공동 편집은 지원되지 않습니다. |
| **제품 내 도우미가 제품 도움말 시스템이 아닙니다** | 대화 도우미는 콘텐츠 생성 및 수정과 같은 강의 편집 작업을 위해 설계되었습니다. 이 동작이 아직 명시적으로 설계되지 않았기 때문에 제품 사용 질문에 대한 응답이 불안정할 수 있습니다. | 방법 관련 질문은 제품 내 도우미에 문의하는 대신 기존 도움말 문서를 사용하십시오. |
