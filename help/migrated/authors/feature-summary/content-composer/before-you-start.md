# 시작하기 전에

Adobe Learning Manager Content Composer를 시작하기 전에 다음 사항을 확인하십시오.

>[!IMPORTANT]
>
>유효한 Adobe Creative Cloud 계정으로 로그인해야 합니다. 아직 계정이 없다면 Adobe Express을 통해 무료 계정을 만들 수 있습니다. 자세한 내용은 [무료 Adobe Express 계정 만들기](https://helpx.adobe.com/kr/express/web/adobe-express-subscription/free.html)를 참조하세요. Adobe 자격 증명을 만든 후 Content Composer를 실행하고 로그인하여 강의 생성을 시작합니다. 조직에 이미 Creative Cloud 구독이 있는 경우 Content Composer에 로그인하기 전에 관리자에게 문의하여 Creative Cloud 계정을 프로비저닝하십시오.

콘텐츠 컴포저를 최대한 활용하려면 **Google Chrome이 권장되는 브라우저입니다**. Firefox와 Safari는 기능이나 동작에서 차이를 보일 수 있습니다.

## 콘텐츠 컴포저의 계정 메뉴 및 환경 설정

Adobe 계정 설정에 액세스하고, 표시 환경 설정을 지정하고, Content Composer 계정 메뉴에서 최근 프로젝트를 엽니다.

콘텐츠 컴포저 도구 모음에는 Adobe 범용 탐색 계정 메뉴가 포함되어 있습니다. 디스플레이 테마와 언어를 조정하고 최근에 작업한 프로젝트를 빠르게 다시 열 수 있습니다.

### 계정 메뉴 열기

콘텐츠 컴포저 도구 모음의 오른쪽 위 모서리에 있는 프로필 아이콘을 선택하여 계정 메뉴를 엽니다.

1. 환경 설정 지정
2. 프로필 아이콘을 선택하여 계정 메뉴를 엽니다.
3. [!UICONTROL 환경 설정]을 선택합니다. [!UICONTROL 환경 설정] 대화 상자가 열립니다.
4. [!UICONTROL 테마]에서 [!UICONTROL 조명] 또는 [!UICONTROL 어둡게]를 선택하여 콘텐츠 컴포저 인터페이스의 표시 모드를 설정합니다.
5. [!UICONTROL 언어]에서 원하는 표시 언어를 선택합니다.
6. [!UICONTROL 저장]을 선택하여 변경 내용을 적용합니다.

>[!NOTE]
>
>테마 및 언어 환경 설정은 Content Composer 인터페이스에만 적용됩니다. 강의 시각적 테마나 강의 콘텐츠 언어에는 영향을 주지 않습니다.

## 최근 프로젝트 열기

계정 메뉴에는 가장 최근에 연 콘텐츠 컴포저 프로젝트를 보여 주는 [!UICONTROL 최근] 목록이 포함되어 있습니다.

[!UICONTROL 최근 항목] 목록에서 프로젝트를 선택하여 직접 엽니다.

## 선택적 요구 사항

* 다룰 주제 영역에 대한 일반적인 아이디어가 있습니다. 시작하기 전에 완전히 명확하게 할 필요는 없습니다.

* AI가 대화를 통해 강의 제목, 대상, 학습 목표를 정의하는 과정을 안내합니다.

* 소스 문서는 선택 사항입니다. 파일을 업로드하지 않고 계속 진행할 수 있으며, AI가 사용자의 입력을 기반으로 콘텐츠를 생성합니다.

* 기존 자료가 있는 경우, 수강신청 대상이 되는 강좌는 Brief 단계에서 업로드 할 수 있습니다. 지원되는 파일 형식은 각각 최대 100MB의 PDF, 마크다운(.md), PowerPoint(.pptx) 등입니다.
