# Adobe Learning Manager Content Composer의 대상

Adobe Learning Manager Content Composer는 처음부터 시작하지 않고 구조화된 강의를 만들어야 하는 모든 사용자를 위해 설계되었습니다.

| **역할** | **콘텐츠 컴포저를 사용하는 방법** |
|-----------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **작성자** | 체계적이고 효과적인 과정을 만듭니다. 자신의 지식을 강의로 전환하거나, 기존 문서 및 소스 자료에서 작업하거나, AI 생성 콘텐츠를 정교하게 조정하여 특정 학습 목표를 달성하는지 여부. |
| **L&amp;D 관리자** | 액세스 권한을 프로비저닝하고, 조직 테마를 설정하고, 완료한 과정을 Adobe Learning Manager에 게시합니다. |
| **L&amp;D 관리자** | 강의가 학습자에게 배포되기 전에 검토하고 승인합니다. |
