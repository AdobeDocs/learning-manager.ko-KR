# Adobe Learning Manager Content Composer 개요

Adobe Learning Manager Content Composer는 모든 과정 생성 단계를 단일 AI 유도 워크플로우로 결합합니다. 학습하고자 하는 내용에 대해 설명하면 해당 제품은 사용자의 입력 내용에 따라 이미지, 지식 점검 및 점수를 매기는 퀴즈 등 체계적인 개요와 전체 강의 내용을 생성합니다.

Content Composer는 학습 생성의 모든 단계를 단일 워크플로우로 가져오고 교수 설계를 이해하는 AI로 공동 생성을 지원하여 더 빠르게 제작할 수 있을 뿐만 아니라 설계로 더 효과적인 학습을 제작할 수 있도록 지원합니다.

강의가 준비되면 다음을 수행할 수 있습니다.

- Publish 과정을 Adobe Learning Manager에 직접 연결하고 포괄적인 학습자 분석을 통해 학습 효과에 대한 실행 가능한 통찰력을 얻습니다.
- 호환되는 LMS에서 사용하려면 SCORM 패키지로 다운로드하십시오.
