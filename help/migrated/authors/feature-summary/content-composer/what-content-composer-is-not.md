# Adobe Learning Manager Content Composer의 기능

시작하기 전에 정확한 기대치를 설정하려면 다음을 수행하십시오.

- 콘텐츠 컴포저는 분기 또는 적응형 학습 경로를 지원하지 않습니다. 강의는 선형 강의 > 주제 구조를 따릅니다.

- 수업 종료 퀴즈는 현재 베타에서 객관식 질문과 참/거짓 질문만 지원합니다. 추가 질문 유형이 로드맵에 나와 있습니다.

## 새로운 기능

시작할 준비가 되면 전체 단계별 워크플로에 대해 [콘텐츠 컴포저로 강의 만들기](#create-course)를 참조하세요.

**앱을 사용해 보세요**. [**콘텐츠 컴포저**](https://contentcomposer.adobe.io/)를 열고 단계별 지침을 따르십시오.

문제가 발생하면 지원 센터에 문의하거나 [Adobe Learning Manager 커뮤니티](https://community.adobe.com/adobe-learning-manager-466)에 쿼리를 게시하십시오.
