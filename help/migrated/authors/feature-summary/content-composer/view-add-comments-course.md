# 강의 보기 및 주석 추가

강의 작성자인 경우 프로젝트에서 **댓글** 패널을 선택하여 댓글을 보고 회신합니다.

1. **주석 패널 열기**: 도구 모음에서 **주석**&#x200B;을 선택합니다. 댓글 패널에는 검토자가 제공한 댓글이 표시됩니다.

2. 댓글을 해결됨으로 표시하거나 댓글을 편집 또는 삭제할 수 있습니다.

3. 필요한 변경 작업을 수행하고 프로젝트를 **저장**&#x200B;합니다.

4. 도구 모음에서 **공유**&#x200B;를 선택하여 최신 링크를 업데이트합니다.
