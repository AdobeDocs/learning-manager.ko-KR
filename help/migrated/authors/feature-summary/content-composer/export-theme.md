# 테마 내보내기

테마를 JSON 파일로 내보내 콘텐츠 컴포저 외부에서 사용자 정의하거나 다른 작성자와 공유할 수 있습니다.

1. 도구 모음에서 **테마**&#x200B;를 선택하여 **강의 테마** 패널을 엽니다.

2. 내보내려는 테마 위에 마우스를 놓고 **내보내기** 아이콘을 선택합니다.
   ![](../assets/47_export_theme_save_as_json_dialog_updated.png)

3. 대화 상자가 나타나면 위치를 선택하고 **파일 이름**&#x200B;을 입력하세요.
