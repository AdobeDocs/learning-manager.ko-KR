# 이미지 편집 또는 추가

![](../assets/16_hierarchy_of_controls_eliminate_substitute_updated.png)

이미지를 선택하여 이미지 도구 모음을 엽니다. 컨트롤에는 다음이 포함됩니다.

- **채우기**, **맞추기:** 프레임 내에서 이미지 크기를 조정하는 방법

- **대체 텍스트** 필드: 이미지 설명을 표시합니다.<br>
  **참고**: 이 텍스트는 수정할 수 없습니다. 이미지에 따라 자동으로 업데이트됩니다.

- **기타 옵션** 아이콘: **이미지의 명도, 채도 및 투명도를 조정**&#x200B;합니다.

이미지를 바꾸려면 **이미지** 아이콘을 선택하여 이미지를 변경합니다. 나만의 파일을 업로드하거나, Adobe Stock을 검색하거나, AI를 사용하여 생성할 수 있습니다.
