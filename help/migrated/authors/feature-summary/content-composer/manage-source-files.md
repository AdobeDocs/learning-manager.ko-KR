# 소스 파일 관리

**소스 관리**&#x200B;를 사용하면 Content Composer에서 과정을 생성하는 데 사용하는 콘텐츠를 제어할 수 있습니다. 강의에 나만의 문서를 추가한 다음, AI를 해당 콘텐츠로만 제한할지 아니면 나만의 지식으로 자료를 보완할지 선택합니다. 문서를 추가하지 않으면 콘텐츠 컴포저는 AI 모델의 기존 지식을 사용하여 강의를 생성합니다.

## 소스 자료를 사용하여 강의 생성

1. 채팅 패널이나 도구 모음에서 **소스 관리** 또는 **파일 추가**&#x200B;를 선택합니다.
   ![](../assets/5_brief_manage_sources_prompt_updated.png)

2. 대화 상자로 파일을 드래그하거나 **개 이상의 소스 파일 추가**&#x200B;를 선택하여 찾아봅니다. 여러 소스 파일을 추가할 수 있습니다.
   ![](../assets/6_manage_sources_no_files_added_updated.png)

3. **출력을 파일의 콘텐츠로 제한**&#x200B;을 선택합니다. 이를 통해 콘텐츠 컴포저는 소스 콘텐츠만 사용하여 강의를 생성할 수 있습니다. 이 옵션을 선택하지 않으면 콘텐츠 컴포저는 웹을 사용하여 과정을 만들기도 합니다.
   ![](../assets/7_manage_sources_file_uploading_restrict_output_updated.png)

지원되는 형식:

| **형식** | **최대 크기** |
|-------------------------|--------------|
| PDF | 100MB |
| 마크다운(.md) | 100MB |
| PowerPoint (.ppt/.pptx) | 100MB |
| MS Word (.doc/.docx) | 100MB |
| 텍스트 파일(.txt) | 100MB |
| 이미지 (.png, .jpg) | 100MB |

강의 개요를 생성하려면 **계속**&#x200B;을 선택하십시오.

### 소스 자료 없이 생성

참조 문서로 소스 파일이 없는 경우 아래 단계를 수행하여 강의 개요를 생성합니다.

1. **원본 관리**&#x200B;를 선택합니다. **원본 관리** 대화 상자가 열립니다.

2. **원본 자료가 없습니다. - 원본 파일을 사용하지 않고 강의 생성**&#x200B;을 선택하여 AI가 일반 지식에서 콘텐츠를 생성할 수 있도록 합니다. 이 옵션을 선택하지 않고 파일이 업로드되면 AI는 생성된 콘텐츠를 업로드된 문서로만 제한합니다.![](../assets/8_manage_sources_no_source_material_option_updated.png)

3. 강의 개요를 생성하려면 **계속**&#x200B;을 선택하십시오.

### 소스 자료 변경 시 강의 업데이트

강의가 이미 생성되면 소스 문서가 최신 상태가 아닐 수 있습니다. 정책이 수정되거나, SOP가 새로운 버전을 받거나, 피치 데크가 업데이트됩니다. 이 작업 과정을 사용하여 현재 재질에 맞게 과정을 다시 표시합니다.

1. 대화 상자를 다시 열려면 채팅 패널이나 도구 모음에서 **소스 관리**&#x200B;를 선택하세요.

2. **개 이상의 소스 파일 추가**&#x200B;를 사용하여 새 파일 또는 수정된 파일을 추가합니다.

3. 소스 목록에 현재 자료만 반영되도록 오래된 파일을 제거하거나 바꿉니다.

4. 계속 을 선택하여 업데이트된 소스 목록을 저장합니다.

5. Content Composer에서 영향을 받는 강의를 다시 생성하고 변경 사항을 검토한 다음 과정을 다시 게시합니다. 다시 게시하면 업데이트가 새 모듈 버전으로 Adobe Learning Manager에 전송됩니다. ALM의 모듈 버전 관리를 참조하십시오.

### 파일 업로드 확인

    ![](../assets/9_manage_sources_file_ingested_confirmation_updated.png)

파일이 첨부되면 도구 모음의 파일 아이콘에 배지 수가 표시됩니다. 도우미가 업로드를 확인하고 **개요 생성** 바로 가기를 제공합니다. 선택하거나 상단 도구 모음에서 **윤곽선 생성**&#x200B;을 선택합니다.
