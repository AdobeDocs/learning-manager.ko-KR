# 가상 코치 템플릿을 사용하여 역할 놀이 만들기

Publish은 처음부터 롤플레이를 빌드하는 대신 템플릿에서 시작하여 몇 분 만에 사전 구축된 Virtual Coach 시나리오를 제공합니다.

Virtual Coach의 **추천** 및 **사용 가능한 템플릿** 섹션에는 영업, 리더십 및 기술 평가 상황을 다루는 사전 구축된 역할 수행 시나리오 라이브러리가 포함되어 있습니다. 템플릿을 사용하는 것은 역할극을 만드는 가장 빠른 방법입니다. 인물, 대화 시작, 주제, 점수가 이미 구성되어 있으며 게시하기 전에 바로 게시하거나 세부 정보를 사용자 정의할 수 있습니다.

템플릿은 도메인, 시뮬레이션 유형 및 언어별로 구성됩니다. 필터를 사용하여 **음성 대화** 또는 **웹캠 연습**&#x200B;과 같은 상호 작용 유형별로 목록을 좁히거나 키워드별로 검색하여 사용 사례와 가장 가까운 시나리오를 찾습니다.

>[!TIP]
>
>템플릿을 선택해도 기본 구성으로 고정되지 않습니다. 개인 배경, 주제, 점수 가중치, 대화 열기를 포함한 모든 필드는 템플릿을 선택한 후 편집할 수 있습니다. 템플릿을 최종 디자인이 아닌 시작점으로 취급하십시오. 구성 가능한 각 필드에 대한 자세한 설명은 [가상 코치 역할 재생 만들기 및 게시](/help/migrated/authors/feature-summary/virtual-coach/create-publish-virtual-coach-role-play.md)를 참조하세요.


1. 작성자로 Adobe Learning Manager에 로그인합니다.
2. 왼쪽 탐색 창에서 **가상 코치**&#x200B;를 선택합니다.
3. **지금 만들기**&#x200B;를 선택합니다.
4. **사용 가능한 템플릿** 섹션을 찾아보거나 **검색** 막대와 도메인, 시뮬레이션 유형 및 언어 필터를 사용하여 시나리오에 맞는 템플릿을 찾습니다.

   ![](/help/migrated/authors/feature-summary/assets/virtual-coach25.png)
5. 템플릿 타일을 선택하여 엽니다. 담당자, 주제 및 점수 구성을 검토합니다.

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach17.png)
   *템플릿을 사용자 지정할지 여부를 결정하기 전에 미리 작성된 대화 컨텍스트와 가상 사용자 배경을 검토하십시오.*

6. 템플릿을 그대로 사용하려면 **Publish**&#x200B;을(를) 선택합니다. 먼저 사용자 정의하려면 섹션을 선택하고 게시하기 전에 관련 필드를 편집합니다.

게시되고 나면 역할극이 **콘텐츠 라이브러리**&#x200B;에 추가되고 작업 지원에 추가되고 강의에 할당될 준비가 됩니다. 해당 단계는 [강의에 가상 코치 역할 놀이 추가](/help/migrated/authors/feature-summary/virtual-coach/add-virtual-coach-role-play-to-course.md)를 참조하거나, [가상 코치로 역할 놀이를 연습](/help/migrated/learners/feature-summary/virtual-coach/practice-role-play-with-virtual-coach.md)하여 학습자 경험을 확인하십시오.
