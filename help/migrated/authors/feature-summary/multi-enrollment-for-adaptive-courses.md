# 적응형 강의에 대한 다중 등록

## 개요

다중 등록을 통해 학습자는 동일한 강의의 둘 이상의 인스턴스에 동시에 등록할 수 있습니다. 이제 Adobe Learning Manager에서 적응형 과정에 대한 다중 등록을 활성화할 수 있습니다.

## 적응 과정의 다중 등록 정보

적응형 강의는 각 학습자에게 사용자 그룹과 일치하는 모듈만 표시합니다. 다중 등록이 켜져 있으면 학습자는 다른 달의 세션과 같이 해당 강의의 여러 인스턴스를 수강할 수 있습니다.

적응형 강의는 인스턴스 수준이 아닌 모듈 수준에서 대기자 목록을 추적합니다. 학습자는 일부 모듈에서 진행 중일 수 있으며 동시에 다른 모듈에 대기가 나열될 수 있습니다. 예를 들어, 강의에는 두 개의 인스턴스가 있고, 각 인스턴스에는 하나의 인원 제한이 있습니다. 첫 번째 학습자가 두 인스턴스에 모두 등록하고 두 시트를 모두 차지합니다. 두 인스턴스에 모두 등록한 두 번째 학습자는 두 인스턴스에 모두 대기자 명단에 나열됩니다.

## 적응 강의에 다중 등록 활성화

1. 작성자로 Adobe Learning Manager에 로그인합니다.
2. 왼쪽 탐색에서 **과정**&#x200B;을 선택합니다. 적응형 과정을 열거나 적응형 과정을 만듭니다.
3. 모듈을 추가합니다. 각 콘텐츠 모듈에 대해 **규칙 추가**&#x200B;를 선택하여 규칙을 볼 수 있는 사용자 그룹과 필수 사용자 그룹을 설정합니다.
4. **저장**&#x200B;을 선택합니다. 다중 등록 옵션을 사용할 수 있게 됩니다.
5. **다중 등록** 토글을 켭니다.
6. 필요한 인스턴스를 만듭니다. 강의실 및 가상 강의실 세션의 경우 인원 제한을 설정합니다.
7. **Publish**&#x200B;을 선택합니다.

학습자는 이제 둘 이상의 강의 인스턴스에 등록할 수 있습니다.

## 인원 제한 및 대기자 명단 행동

적응형 강의는 각 강의실 또는 가상 강의실 세션에 대해 인원 제한을 적용합니다. 학습자는 즉시 등록되며 전체 세션에만 대기자 명단에 등록됩니다. 학습자는 다른 모든 모듈을 즉시 시작할 수 있습니다.

| 조건 | 결과 |
|------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------|
| 보이는 모든 세션에 사용 가능한 시트가 있습니다. | 학습자는 모든 모듈에 대한 전체 액세스 권한으로 등록됩니다. |
| 하나 이상의 표시되는 세션이 가득 찼습니다. | 학습자는 전체 세션에만 등록되고 대기자 명단에 등록됩니다. |
| 등록된 학습자가 있는 강의에 시트가 없는 필수 세션을 추가합니다 | 학습자가 새 세션에 대기자 명단에 등록됩니다. 기존 진행 상황 및 액세스 권한은 영향을 받지 않습니다. |
| 사용자 그룹 변경은 학습자가 볼 수 있는 모듈에서 세션을 제거합니다 | Adobe Learning Manager은 즉시 자리를 비운다. |
| 학습자가 다른 인스턴스로 전환합니다 | 완료된 모듈은 완료된 상태로 유지됩니다. 시트는 학습자가 완료하지 않은 표시된 모듈에만 사용됩니다. |

## 적응형 학습 경로에 대한 등록 및 완료 규칙

이제 작성자는 Adobe Learning Manager에서 적응형 학습 경로에 적응형 강의를 추가할 수 있습니다. 등록, 대기자 명단 및 완료는 작성자가 구성하는 섹션 설정과 강의 설정을 결합하는 규칙을 따릅니다.

### 적응형 학습 경로가 학습자를 평가하는 방법

Adobe Learning Manager은 섹션 수준과 과정 수준에서 가시성을 평가합니다. 섹션 규칙은 학습자가 섹션과 그 안의 적응형 강의를 볼 것인지 여부를 결정합니다. 각 적응형 과정 내의 모듈 규칙은 학습자가 과정에 등록되었는지 여부를 결정합니다.

학습자는 적응형 LP 내 적응형 강의에 대한 UG가 변경될 때마다 자동 등록됩니다. 또한 학습자는 자동 등록 알림과 전자 메일을 수신합니다.

### 등록 평가 규칙

적응형 학습 경로에 학습자를 등록하면 Adobe Learning Manager에서 다음 순서로 경로를 확인합니다.

| 순서 | 확인 | 결과 |
|-----------|----------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1 | 섹션 표시 여부 | Adobe Learning Manager은 강의 섹션이 학습자에게 보이는 경우에만 등록 여부를 확인합니다. |
| 2 | 강의 자격 | 강의에 학습자를 위한 필수 모듈이 없으면 학습자가 강의에 등록되지 않습니다. 이 강의는 학습 경로 완료에는 적용되지 않습니다. |
| 3 | 적격 과정이 없는 섹션 | 섹션에 적응형 강의만 포함되어 있고 학습자가 해당 강의를 수강할 자격이 없는 경우 Adobe Learning Manager에서 해당 섹션을 건너뜁니다. |
| 4 | 학습 과정 등록 | 학습자에게 적용되는 필수 섹션이 없으면 학습자가 학습 경로에 등록되지 않은 것입니다. |

학습자가 학습 경로 인스턴스에 속한 강의 인스턴스에 이미 등록되어 있으면 Adobe Learning Manager에서 해당 등록을 사용합니다.

등록 후에는 다음 규칙이 적용됩니다.

* 가시성으로 인해 처음에 강의를 건너뛰었던 학습자는 나중에 가시성/필수 규칙이 변경되어 적응형 강의가 표시되면 자동 등록될 수 있습니다.
* 사용자 그룹 변경 또는 강의 변경으로 적응형 강의에서 학습자의 등록이 취소될 수 있습니다. 경로에 필수 콘텐츠가 없는 경우 학습자는 경로에서 등록이 취소됩니다.
* 섹션 변경의 경우 학습자는 자동 등록 알림 또는 전자 메일을 받지 않습니다. 페이지를 다시 로드하면 학습자는 변경 사항을 확인할 수 있습니다.

### 적응형 학습 경로의 대기자 명단 동작

대기자 명단은 인스턴스 레벨이 아닌 세션 레벨에서 작동합니다. 이는 학습 경로의 적응 과정에도 적용됩니다.

| 시나리오 | 비헤이비어 |
|----------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------|
| 경로에 강의실 또는 가상 강의실 모듈이 없는 적응형 강의 | 대기자 명단이 적용되지 않습니다. |
| 적응형 강의에는 강의실 또는 가상 강의실 모듈이 있고 인스턴스가 선택되지 않았습니다 | 강의의 기본값은 **인스턴스 없음**&#x200B;입니다. 학습자는 모든 인스턴스에 등록할 수 있으며 가득 찬 세션에만 대기자 명단에 나열됩니다. |
| 등록 전에 인스턴스 선택 | 학습자는 해당 인스턴스에 등록되어 있으며 가득 찬 세션에만 대기자 명단에 나열됩니다. |

대기자 명단에 등록된 학습자를 관리하려면 적응형 과정을 열고 **학습자** > **대기자 명단** 탭을 선택합니다. 유연한 학습 경로 및 적응형 학습 경로에 포함된 적응형 과정의 경우 대기자 명단에 등록된 학습자는 과정의 **대기자 명단** 탭에만 표시되며 학습 경로에 표시되지 않습니다.

### 새로 고침 완료 및 롤백 동작

Adobe Learning Manager은 사용자 그룹 또는 규칙이 변경될 때 자동으로 완료를 해지하지 않습니다. 완료한 학습자는 새로 고침한 완료 시점까지 완료 상태를 유지합니다.

* 학습 경로에서 **완료 새로 고침**&#x200B;을(를) 실행합니다. 학습 경로를 통해 적응형 강의를 듣는 학습자 스스로 해당 강의를 새로 고칠 수 없습니다.

* 각 적응형 강의는 학습자의 현재 필수 모듈을 기반으로 먼저 재계산됩니다. 그런 다음 현재 필수 섹션과 새로 고침된 강의 상태를 기반으로 학습 경로가 다시 계산됩니다.

* 강의 또는 경로가 더 이상 완료되지 않으면 학습자의 상태가 진행 중으로 변경됩니다. 원래 완료는 학습자 성적 증명서에 기록 기록으로 유지됩니다.

* 완료 롤백은 사용자 그룹 변경 또는 재게시로 인해 모듈이 변경된 적응 강의를 찾습니다. 이렇게 하면 해당 강의와 학습 경로가 다시 계산됩니다. 롤백이 완료되면 작업 상태가 **성공**&#x200B;을 표시합니다.

대기자 명단은 모듈 수준에서 추적됩니다. 학습자는 둘 이상의 인스턴스에서 전체 세션에 대기자 명단에 등록될 수 있습니다. 예를 들어, 강의의 경우 좌석 제한이 각각 한 개씩 있는 인스턴스가 두 개 있습니다. 첫 번째 학습자가 두 인스턴스에 모두 등록하고 두 시트를 모두 차지합니다. 두 인스턴스에 모두 등록한 두 번째 학습자는 각 인스턴스의 **대기자 명단** 탭에 나타납니다.

### 대기자 명단에 등록된 학습자에게 시트 할당

학습자가 등록을 취소하거나, 작성자가 인원 제한을 늘리거나, 학습자가 인스턴스를 전환하면 Adobe Learning Manager에서 등록 날짜 순서로 대기자 목록을 지웁니다. 시트를 수동으로 할당할 수도 있습니다.

1. 적응 과정을 엽니다.
2. **학습자** > **대기자 명단** 탭을 선택합니다.
3. 시트를 할당할 각 학습자 옆에 있는 확인란을 선택합니다.
4. **시트 할당**&#x200B;을 선택합니다.

Adobe Learning Manager은 대기 목록에 있는 모든 세션의 대기자 명단에서 선택한 각 학습자를 지웁니다. 보고 있는 세션뿐만 아니라. 시스템은 학습자용 시트를 배치했다고 가정합니다.
