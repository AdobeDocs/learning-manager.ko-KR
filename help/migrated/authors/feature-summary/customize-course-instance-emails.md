## Email Builder에서 강의 및 인스턴스 이메일 사용자 정의

Adobe Learning Manager에서 Email Builder와 관리자가 제공하는 레이아웃을 사용하여 강의 레벨 및 인스턴스 레벨 이메일을 사용자 정의합니다.

작성자는 강의 또는 강의의 특정 인스턴스에 대한 전자 메일을 사용자 정의할 수 있습니다. 두 절차 모두 관리자가 제공하는 레이아웃에서 시작됩니다.

### 강의 레벨 이메일 사용자 정의

1. 강의를 엽니다.
2. **전자 메일 템플릿**&#x200B;을 선택합니다.
3. **강의 전자 메일 레이아웃**&#x200B;을 선택합니다.
4. 전자 메일 콘텐츠를 사용자 지정합니다. 글꼴, 색상, 행 및 단추를 설정합니다.
5. 템플릿을 저장 합니다.
6. 강의 Publish.

### 인스턴스 수준 이메일 사용자 정의

여러 코호트에 서로 다른 메시지가 필요한 경우 인스턴스 수준 이메일을 사용하십시오. 강의 인스턴스를 통해 이들 코호트를 관리합니다.

1. 강의 인스턴스를 엽니다.
2. **전자 메일 작성기**&#x200B;를 엽니다.
3. 사용 가능한 레이아웃을 선택하거나 인스턴스가 이미 사용하는 레이아웃을 상속합니다.
4. 메시지 내용을 업데이트합니다.
5. 템플릿을 저장 합니다.

>[!NOTE]
>
>둘 다 있는 경우 인스턴스 수준 전자 메일은 강의 수준 템플릿을 재정의합니다.

### 제목 변수 및 이메일 헤더 이미지 사용

이미지 구성 요소와 함께 Title 변수를 사용하여 Banner 구성 요소 대신 이메일 헤더를 작성합니다. Outlook과 같은 일부 전자 메일 클라이언트에는 배너 구성 요소의 이미지가 표시되지 않습니다.

Title 변수인 EmailTitle은 기존 ChannelName 변수와 동일하게 작동합니다. 각 전자 메일에는 고유한 기본 제목 값이 있습니다.

제목 헤더를 추가하려면 다음을 수행하십시오.

1. 머리글 이미지에 대한 이미지 구성 요소를 추가합니다.
2. Text 구성 요소를 추가하고 구성 요소의 구성 창에 있는 변수 드롭다운에서 제목 변수를 삽입합니다.
3. 텍스트 구성 요소를 가운데 정렬합니다. 전체 레이아웃에서 상단 헤더에 배치합니다.

개별 전자 메일은 기본적으로 전역 레이아웃의 헤더를 사용합니다. 개별 이메일에서 텍스트 구성 요소를 편집하여 다음을 수행할 수 있습니다.

1. 변수를 사용자 정의 텍스트로 바꾸기
2. 변수 앞 또는 뒤에 텍스트를 추가하고 `EmailTitle` 유지

이미지를 배너 구성 요소에 추가하면 Email Builder에 일부 전자 메일 클라이언트에서 이미지가 올바르게 표시되지 않을 수 있다는 경고가 표시됩니다. 이 경고에서는 대신 이미지 구성 요소와 제목 변수를 사용할 것을 권장합니다.

### 문제 해결

**레이아웃을 선택할 수 없습니다.**
레이아웃 상속은 사용 가능한 마스터 레이아웃에 따라 달라집니다. 관리자에게 계정 레이아웃을 만들도록 요청하십시오.

**전자 메일에 최근 레이아웃 변경 내용이 표시되지 않습니다.**
템플릿이 레이아웃에서 연결 해제되었을 수 있습니다. 연결되지 않은 템플릿은 더 이상 레이아웃 업데이트를 받지 않습니다.

**인스턴스의 학습자에게 강의 전자 메일과 다른 전자 메일이 전송됩니다.**
인스턴스 수준 전자 메일은 강의 수준 템플릿을 재정의합니다. 인스턴스 레벨 템플릿을 검토합니다.

**강의 또는 인스턴스 전자 메일에 Email Builder가 표시되지 않습니다.**
Adobe을 통해 Email Builder가 단계적으로 활성화됩니다. 관리자에게 문의하여 계정에 Email Builder가 활성화되어 있는지 확인하십시오.

**배너 이미지가 전자 메일에 표시되지 않습니다.**
Outlook과 같은 일부 전자 메일 클라이언트는 배너 구성 요소의 이미지를 표시하지 않습니다. Banner 구성 요소를 제거하고 이미지 구성 요소를 추가하고 제목 변수를 사용하는 Text 구성 요소를 추가합니다.
