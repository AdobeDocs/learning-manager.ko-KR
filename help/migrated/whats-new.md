# Adobe Learning Manager 2026년 12월 릴리스의 새로운 기능

Adobe Learning Manager의 이번 릴리스에서는 플랫폼을 간소화하고 기능을 확장하기 위해 다양한 새로운 기능과 개선 사항을 소개합니다. 이러한 업데이트는 일상적인 워크플로우를 간소화하고, 학습 콘텐츠가 구성 및 전달되는 방식을 개선하며, 전반적인 경험을 보다 일관되고 직관적으로 만듭니다.

## Report Builder 차트 및 대시보드

이제 Adobe Learning Manager이 Report Builder에서 차트 및 대시보드를 지원하여 관리자가 플랫폼 내에서 직접 보고서 데이터를 시각화할 수 있습니다. 관리자는 보고서 열에서 각 차트에서 합계 및 필터링을 사용할 수 있는 차트를 생성할 수 있습니다.

Report Builder에서 지원하는 차트 유형은 다음과 같습니다.

* 큰 수
* 선 그래프
* 막대 그래프
* 파이 차트
* 피벗 테이블

보고서 대시보드에는 하나의 보고서에서 빌드된 차트가 포함됩니다. 사용자 정의 대시보드는 등록 및 사용자 데이터와 같은 여러 보고서의 차트를 결합하고 최대 20개의 위젯을 지원합니다. 보고서를 공유하면 보고서에 속한 차트가 공유됩니다. 이를 통해 책임자는 보고서를 다시 실행하지 않고 현재 보고서 데이터를 하나의 보기로 유지할 수 있습니다. 차트는 최대 10,000개의 데이터 포인트를 표시하고 피벗 테이블은 최대 100개의 행과 100개의 열을 표시합니다. 차트가 한도를 초과하면 필터를 적용하여 결과를 좁힙니다. 대시보드는 아직 내보낼 수 없습니다.

[자세히 알아보기](/help/migrated/administrators/feature-summary/report-builder-visualization.md)

## Report Builder의 Insights 상담사 보고서

이제 관리자는 Report Builder에서 Insights 상담사의 답변을 계속 사용할 수 있습니다. Insights 에이전트가 질문에 답변하면 Report Builder은 동일한 쿼리를 병렬 단계의 자체 필드에 매핑합니다. 관리자는 보고서를 열고, 검토하고, 편집하고, 저장할 수 있습니다. 여기에서 구독과 같은 다른 보고서와 동일한 Report Builder 기능을 사용할 수 있습니다.

질문의 일부를 Report Builder 필드로 표시할 수 없는 경우 보고서에는 해당 부분이 간격으로 나열됩니다. 누락된 부분이 질문의 핵심인 경우에는 보고서가 제공되지 않습니다. 복잡한 쿼리를 사용하면 결과가 줄어들 수 있으므로 의존하기 전에 각 보고서를 검토하십시오.

[자세히 알아보기](/help/migrated/administrators/feature-summary/insights-agent.md#create-report-insights-agent)

## Adobe Experience Manager Assets 통합

이제 Adobe Learning Manager이 Adobe Experience Manager Assets과 통합되면서 작성자는 중앙 집중식 리포지토리에서 승인된 학습 콘텐츠 및 이미지 에셋에 직접 액세스하고 사용할 수 있습니다. 이렇게 하면 디지털 에셋 관리자(DAM)에서 에셋을 관리하는 팀과 Adobe Learning Manager에서 강의를 빌드하는 팀 간의 수동 다운로드 및 업로드 단계가 제거됩니다.

변경 사항:

* **승인된 에셋 액세스:** 작성자는 Adobe Learning Manager을 종료하지 않고 Experience Manager Assets에서 에셋을 검색하고 선택하므로 강의는 최신 상태가 아닌 현재 승인된 파일을 사용합니다.
* **강의 에셋을 최신 상태로 유지:** 에셋이 DAM에서 변경되면 에셋이 수정될 때 콘텐츠를 일관되게 유지하여 자동으로 업데이트를 강의가 제공될 수 있습니다.
* **액세스는 기존 권한을 따릅니다.** 작성자는 Experience Manager Assets에서 이미 액세스 권한이 있는 에셋만 볼 수 있으므로 Adobe Learning Manager에서 검색하는 경우 DAM 자체와 동일한 권한이 적용됩니다.

그 결과, 에셋에서 학습자로의 단일 관리 경로가 만들어지고, 수동 작업이 줄어들며 버전 불일치가 줄어듭니다.

[자세히 알아보기](/help/migrated/integration-admin/feature-summary/aem-assets-integration.md)

## 파일 제출 개선 사항

이제 파일 제출 모듈에서 팀 제출 및 루브릭 기반 평가를 지원합니다. 새로운 설정은 제출에 강사 승인이 필요한지 여부도 제어합니다.

### 팀 제출

이제 강사가 파일 제출을 위한 팀을 만들 수 있습니다. 각 팀은 전체 팀을 위해 하나의 파일을 제출합니다. 강사가 제출물을 한 번 평가하면 그 결과는 모든 구성원에게 적용됩니다. 팀 양식은 강사가 수동으로 작성하거나 예약된 프로세스가 팀당 멤버 또는 팀 수를 기반으로 인스턴스 시작 날짜 전에 작성한다는 두 가지 방법으로 구성됩니다.

강사는 새로운 **팀 관리** 페이지에서 팀을 관리하고 팀 제출 페이지에서 작업을 검토합니다. 강사는 팀원이 나갔을 때와 같이 변경이 필요한 경우, 승인된 제출을 제출 취소하여 팀의 잠금을 해제할 수 있습니다. 한 팀은 최대 100명의 멤버를 보유합니다. 학습자는 팀, 멤버 및 평가 결과를 볼 수 있습니다. 강의를 게시한 후에는 팀 모듈을 추가하거나 삭제할 수 없습니다.

[자세히 알아보기](/help/migrated/learners/feature-summary/submit-assignment-as-team.md)

### 루브릭 기반 평가(평가 계획)

작성자는 이제 파일 제출 모듈에 대해 평가 계획이라는 루브릭을 정의할 수 있습니다. 루브릭은 채점된 선택지로 객관적인 질문을, 서면검토로 주관적인 질문을 지원한다.

또한 작성자는 다음 설정을 구성할 수 있습니다.

* 학습자가 제출하기 전에 루브릭 기반 평가 질문을 볼 것인지 여부
* 채점이 전체 점수 하나인지 각 기준에 대한 점수인지 여부

각 질문은 필요에 따라 표시할 수 있으며 검토자의 의견을 들을 수 있도록 구성할 수 있습니다. 루브릭 기반 평가는 최대 100개의 질문을 포함하며 작성자는 각 로케일에 대해 질문을 별도로 입력합니다. 강의를 게시한 후에는 질문 텍스트만 변경할 수 있습니다.

[자세히 알아보기](/help/migrated/administrators/feature-summary/team-submissions-and-rubrics.md)

### 강사 승인 또는 자동 완료

이제 작성자는 파일 제출에 강사 승인이 필요한지 또는 자동으로 완료되는지를 선택할 수 있습니다. 이 설정은 평가 계획과는 별개입니다.

## 학습자 도우미용 모델 컨텍스트 프로토콜 서버

ALM을 사용하면 학습자가 MCP(Model Context Protocol) 서버를 통해 이미 사용하는 도구로 학습에 액세스할 수 있습니다. 학습자는 ChatGPT, Claude, 사용자 정의 에이전트 등 어디서나 Learning Manager에 액세스할 수 있습니다. 통합 책임자 앱에서 서버를 구성하여 책임자가 학습자를 위한 6개의 핵심 도구에 액세스할 수 있도록 합니다. 여기에는 두 가지 학습자 도우미 도구(응답 상담사 및 개인화된 학습 경로)가 포함됩니다.

서버는 다음과 같은 기능을 제공합니다.

* 검색
* 등록 목록
* 학습 객체 가져오기
* 사용자 프로필 가져오기
* 학습 콘텐츠 질문에 답변
* 개인화된 학습 경로 가져오기

관리자는 각 도구 설명을 편집하여 조직별 예제를 추가할 수 있습니다. 클라이언트는 서버 메타데이터에서 인증 세부 정보를 읽으므로 클라이언트 ID와 클라이언트 암호만 있으면 됩니다.

[자세히 알아보기](/help/migrated/integration-admin/feature-summary/configure-alm-mcp-server.md)

## 개인화된 학습 경로 편집 및 브랜딩 스트립

* 학습자는 이제 채팅을 통해 주제 및 강의 목록을 구체화하는 기존 옵션에 더해 제안된 주제나 강의를 한 단계로 제거할 수 있습니다.
* 이제 책임자는 브랜딩 페이지를 통해 학습자 홈 페이지에서 개인화된 학습 경로 스트립의 위치를 변경할 수 있습니다.

[자세히 알아보기](/help/migrated/administrators/feature-summary/customize-learner-homepage.md#add-reorder-homepage-strips)

## Virtual Coach에서 역할극으로 기술 연습

Adobe Learning Manager은 이제 학습자가 직장에서 직면하기 전에 현실적인 직장 대화를 연습할 수 있도록 하는 AI 기반 역할 재생 및 코칭 솔루션인 Virtual Coach를 제공합니다. 영업 이의신청, 고객 에스컬레이션, 성과 검토 등이 그 예입니다.

작성자는 템플릿이나 AI 비서를 사용하여 자신의 참조 자료에서 시나리오를 만들고 학습자는 실시간으로 응답에 적응하는 AI 캐릭터로 말합니다. 각 세션 후 학습자는 지식과 커뮤니케이션 스타일에 대해 작성자가 정의한 기준에 따라 측정한 점수 및 코칭 피드백을 즉시 받을 수 있습니다.

Virtual Coach는 9개의 언어를 지원하며, 개별 작업 지원으로 사용하거나 강의에 내장할 수 있습니다.

[자세히 알아보기](../migrated/authors/feature-summary/virtual-coach/what-virtual-coach-is.md)

## 학습자 도우미의 학습 경로 인용

학습자 도우미 답변에서는 이제 강의 자체와 함께 소스 강의가 포함된 학습 경로를 인용합니다. 학습자는 인용에서 강의 개요 또는 학습 경로 페이지를 엽니다. 작업 지원에서 받은 답변에는 다운로드 링크가 포함됩니다. 그러면 학습자가 질문에 답변하는 교육을 찾을 수 있습니다.

[자세히 알아보기](/help/migrated/learners/feature-summary/learner-ai-assistant.md#learning-path-citations)

## AI 어시스턴트 구성

관리자 도우미에서는 Insights 에이전트와 Knowledge Agent라는 두 개의 에이전트를 제공합니다. 개별적으로 구성할 수 있습니다. 학습자 도우미에서는 지식 상담사, 대답 상담사, 학습 경로 상담사의 세 가지 상담사를 제공합니다. 카탈로그 구성과 함께 구성할 수 있습니다.

[자세히 알아보기](/help/migrated/learners/feature-summary/learner-ai-assistant.md#configure-la-agents)

## 강사가 학습 개체 인스턴스를 편집할 수 있는 Webhook

이제 학습 개체 인스턴스 수정 Webhook는 강사가 가상 강의실 세션을 편집하고 책임자와 작성자가 변경하면 트리거됩니다. 세션 시간, 장소 및 등록 제한과 같은 변경 사항이 이를 트리거합니다. 그러면 헤드리스 고객은 공개 API를 통해 세션 세부 정보를 검색하고 업데이트를 학습자에게 전달할 수 있습니다.

[자세히 알아보기](/help/migrated/integration-admin/feature-summary/webhook-instructor-edits.md)

## 준수 위젯에 다중 등록된 강의

이제 준수 위젯에 학습자가 완료해야 하는 다중 등록 강의의 모든 인스턴스가 나열됩니다. 각 항목은 인스턴스 이름을 표시합니다. 하나의 인스턴스에 기한이 있는 경우 기한이 없는 인스턴스는 숨겨집니다. 공용 API의 등록 엔드포인트는 선택적 매개 변수를 통해 동일한 동작을 지원합니다.

[자세히 알아보기](/help/migrated/api-changes-dec-2026.md#api-multienrolled-instances-lc-widget)

## 가상 강의실 세션 초대 다시 보내기

강의 편집 권한이 있는 관리자는 이제 인스턴스 페이지에서 세션 초대를 재보낼 수 있습니다. **재전송**&#x200B;을 선택하고 학습자를 검색한 후 보내십시오. 이 옵션은 현재 및 향후의 가상 강의실 세션에 사용할 수 있습니다. 여러 인스턴스에 있는 학습자의 경우 선택한 인스턴스로만 초대가 이동합니다. 세션에 등록되지 않은 학습자는 경고와 함께 건너뜁니다.

[자세히 알아보기](/help/migrated/instructors/feature-summary/resend-session-invite.md)

## Adobe Connect 레코딩 보기에서 자동 출석

이제 Adobe Learning Manager은 학습자가 누락된 가상 교실 세션 기록을 재생할 때 출석을 표시합니다. 예약된 통합은 Adobe Connect에서 뷰어 데이터를 가져와 재생 시간과 계정에 대해 설정된 완료 조건을 비교합니다. 책임자가 통합 책임자 앱에서 일정을 설정합니다. Adobe Learning Manager은 출석을 결정할 때 실제 시청 시간만 고려하므로 녹화를 건너뛰는 것은 완료 기준에 포함되지 않습니다.

## 강의 및 인스턴스용 Email Builder

Adobe Learning Manager의 Email Builder를 사용하면 책임자와 작성자가 브랜디드 학습자 커뮤니케이션 템플릿을 만들 수 있습니다. ALM의 2026년 12월 릴리스에서는 강의 레벨 및 인스턴스 레벨 이메일에서 전체 Email Builder 환경을 사용할 수 있습니다. 작성자는 관리자가 정의한 레이아웃과 서식을 상속하면서 이러한 전자 메일을 사용자 정의할 수 있습니다.

Email Builder를 사용하여 다음을 수행할 수 있습니다.

* 재사용 가능한 이메일 레이아웃 만들기
* 조직 브랜딩 적용
* 배너 및 서명 사용자 정의
* 기본 글꼴 및 색상 정의
* 강의 및 학습 프로그램 간 커뮤니케이션 표준화

관리자가 계정 전체 이메일 템플릿과 레이아웃을 만듭니다. 작성자는 템플릿을 처음부터 다시 작성하지 않고도 과정 및 인스턴스 수준에서 이메일을 사용자 정의할 수 있습니다.

배너 및 서명 설정이 이동되었습니다. 이전에는 이러한 설정이 별도의 **설정** 탭에 나타났습니다. 해당 탭이 제거되고 **배너** 및 **서명**&#x200B;이 이제 **전역 레이아웃**&#x200B;에 나타납니다.

Email Builder를 사용하면 제목 변수를 사용하여 이메일 제목을 추가할 수 있습니다.

### Email Builder 계층 구조의 작동 방식

Email Builder는 계층 구조를 사용합니다. 각 수준은 상위 수준에서 상속되며 로컬 사용자 지정을 허용합니다.

| **수준** | **제공 항목** | **사용자 지정 대상** |
|----|----|----|
| 계정 레이아웃 | 브랜딩, 글꼴, 색상, 머리글 및 바닥글 구조 | 관리자 |
| 계정 템플릿 | 글로벌 이메일 스타일, 공통 메시징 구성 요소 및 공유 브랜딩 | 관리자 |
| 강의 템플릿 | 등록 메시지, 강의 미리 알림, 완료 이메일 및 세션 알림과 같은 강의별 이메일 | 작성자 |
| 인스턴스 템플릿 | 코호트별, 세션별 또는 지역별 메시지와 같은 가장 높은 수준의 사용자 지정 | 작성자 |

모든 강의는 계정 템플릿에서 상속할 수 있습니다. 강의 전자 메일은 조직의 레이아웃을 상속하고 콘텐츠를 사용자 정의할 수 있습니다.

### 레이아웃 상속 정보

템플릿은 사용 가능한 가장 가까운 레이아웃에 연결됩니다. 인스턴스 레벨 템플릿이 있는 경우 인스턴스 레벨 레이아웃에 연결됩니다. 없는 경우 템플릿은 가장 가까운 마스터 레이아웃에 연결됩니다. 레이아웃의 출처를 확인할 수 있습니다.

템플릿이 레이아웃에 연결된 경우:

* 브랜딩은 자동으로 템플릿에 적용됩니다
* 작성자는 콘텐츠만 업데이트합니다
* 메시지 중복 감소

레이아웃에서 템플릿 연결을 해제할 수 있습니다. 템플릿 연결을 해제한 후:

* 템플릿은 기존 디자인을 유지합니다
* 향후 레이아웃 업데이트는 템플릿에 영향을 주지 않습니다
* 템플릿이 개별적으로 편집 가능해짐

레이아웃 상속은 사용 가능한 마스터 레이아웃에 따라 달라집니다. 둘 다 있는 경우 인스턴스 수준 전자 메일은 강의 수준 템플릿을 재정의합니다.

### 관리자와 작성자가 작업을 공유하는 방법

관리자는 계정 레이아웃을 만들고, 계정 템플릿을 만들고, 브랜딩을 게시합니다. 그러면 작성자는 레이아웃을 상속하고 강의 이메일을 사용자 정의하며 템플릿을 저장하고 강의를 게시합니다. 작성자는 코호트가 강의 인스턴스를 통해 관리하는 다른 메시지가 필요한 경우 인스턴스 수준 템플릿을 사용합니다.

### 강의 및 인스턴스 전자 메일의 Email Builder 가용성

계정에 대해 Email Builder가 이미 활성화된 경우 새 변경 사항이 자동으로 수신되며 별도의 조치를 취할 필요가 없습니다. 기존 이메일 기능은 Email Builder 마이그레이션 작업과 별개로 계속 작동합니다.

## Adobe Workfront에서의 세션 취소 동기화

Adobe Workfront에서 취소된 세션은 수동 단계 없이 마이그레이션 프로세스를 통해 Adobe Learning Manager으로 이월됩니다. 마이그레이션은 **활성** 또는 **취소됨**&#x200B;을 수락하는 선택적 **상태** 열을 추가합니다. 값이 비어 있으면 세션이 변경되지 않습니다. 마이그레이션을 통해 수행한 취소는 Learning Manager 인터페이스에서 수행한 취소와 동일하게 작동합니다. 학습자, 강사, 책임자, 작성자 및 관리자는 동일한 취소 전자 메일을 받습니다.

취소된 세션에는 두 가지 동작이 적용됩니다.

* 마이그레이션은 취소된 세션에 세부 변경 사항을 적용하지 않고 해당 행에 대한 유효성 검사 오류를 반환합니다.
* 상태를 활성으로 설정하면 세션이 다시 활성화되며 해당 세부 정보를 업데이트하거나 다시 취소할 수 있습니다.

세션 업데이트는 이전과 동일하게 계속 작동합니다.

## 이름에 대한 문자 제한

이제 Adobe Learning Manager은 63자에서 최대 255자의 이름을 사용할 수 있습니다. 이는 CSV 가져오기 및 자체 등록을 통해 인터페이스에 추가된 사용자에게 적용되므로 다른 시스템에서의 사용자 동기화가 더 이상 긴 이름으로 실패하지 않습니다.

이는 외부 시스템에서 사용자를 마이그레이션하거나 사용자 생성을 자동화할 때 특히 유용합니다.

2026년 12월 릴리스부터 이름 필드는 최대 255자를 사용할 수 있습니다. 이전 릴리스에서는 최대 63자까지 허용됩니다.

>[!NOTE]
>
>이 제한은 역할과 관계없이 계정의 모든 사용자에게 적용됩니다. 기존 사용자와 해당 이름은 이 변경의 영향을 받지 않습니다.

다음과 같은 방법으로 사용자를 추가하거나 편집할 때 긴 이름을 입력할 수 있습니다.

* 관리 인터페이스에 단일 사용자 추가
* 기존 사용자 편집
* CSV 파일로 사용자 가져오기
* 자체 등록을 통해 사용자 등록
* 외부 사용자 추가

긴 이름은 인터페이스의 일부 영역에서 사용할 수 있는 공간보다 넓을 수 있습니다. 레이아웃을 읽을 수 있도록 Adobe Learning Manager은 다음과 같은 작은 영역에서 긴 이름을 줄입니다.

* 표 셀
* 드롭다운 목록 항목
* 검색 결과

전체 이름을 보려면 단축된 이름 위에 마우스를 올려놓습니다.

## 임시 방문 기능 개선 사항

이제 Learning Manager를 사용하면 사용자가 로그인하지 않고도 학습 콘텐츠에 대한 액세스를 제어할 수 있습니다. 책임자는 공개 카탈로그를 지정할 수 있으며, 작성자는 계정 없이 사용할 수 있는 강의와 모듈을 결정할 수 있습니다. 공개 콘텐츠는 크롤링 가능하고 AI가 읽을 수 있는 페이지로 게시되어 검색 엔진과 Claude, ChatGPT 등 AI 비서를 통해 아카데미를 발견할 수 있다. 익명 사용은 방문자별로 추적되며 로그인 사용과 별도로 보고됩니다.

### 로그인하지 않고 콘텐츠 사용

이제 공개 아카데미 방문자는 계정, 이메일 또는 양식 없이 과정 개요 페이지에서 선택한 콘텐츠를 바로 재생할 수 있습니다.

* **로그인하지 않은 액세스 설정 또는 해제:** 관리자는 전체 계정에 대해 로그인하지 않은 콘텐츠 사용을 설정하거나 해제할 수 있습니다.
* **로그인하지 않고 강의나 모듈을 사용할 수 있게 만들기:** 작성자는 로그인 없이 전체 강의를 사용할 수 있게 하거나, 게이티드 고급 콘텐츠 앞에 무료 입문 모듈과 같은 특정 모듈만 열 수 있습니다.
* **강의에서 설정 상속:** 학습 경로 및 인증은 추가 설정 없이 강의 설정을 따릅니다.
* **로그인하지 않고 콘텐츠 보기:** 인증되지 않은 학습자는 계정에 로그인하지 않고도 사용할 수 있는 로그인하지 않은 콘텐츠를 볼 수 있습니다.
* **자가 진행식 콘텐츠만:** 로그인 없이는 서드파티 라이선스 콘텐츠 및 획득한 카탈로그 콘텐츠를 사용할 수 없습니다.
* **익명 소비에 대한 보고서:** 매월 로그인하지 않은 소비에 대한 보고서를 생성할 수 있습니다.
* **플랫폼 간 임시 방문 학습 활성화:** 임시 방문 콘텐츠 소비는 웹 및 모바일의 기본 Adobe Learning Manager, 헤드리스 배포 및 Adobe Experience Manager Sites 위젯 기반 아카데미에서 지원됩니다.

### 공개 카탈로그를 선택하십시오.

이제 관리자는 공공 아카데미에 나타나는 특정 카탈로그를 선택할 수 있습니다. 해당 카탈로그만 익명 방문자가 검색하고 검색 엔진과 AI 비서가 인덱싱할 수 있으므로 테스트 과정 또는 내부 콘텐츠는 비공개로 유지됩니다.
 
### 검색 엔진 및 AI 도우미(Beta)에서 찾을 수 있음

이제 Adobe Learning Manager은 Google과 같은 검색 엔진과 ChatGPT, Claude, Gemini와 같은 AI 도우미를 통해 공공 아카데미를 발견하게 할 수 있습니다. 그러면 사용자의 아카데미가 지정한 검색 결과 및 AI 생성 답변에 강의가 표시됩니다.

* 계정 수준 컨트롤을 사용하면 책임자가 크롤러가 공개 아카데미에 액세스할 수 있는지 여부와 해당 콘텐츠를 인덱싱할 수 있는지 여부를 결정할 수 있습니다.
* 각 아카데미는 자체 sitemap과 robots.txt를 얻는데, 이는 여러분이 공개한 카탈로그에서 자동으로 생성됩니다.
* 페이지는 크롤러용으로 미리 렌더링되므로 JavaScript를 실행하지 않는 AI 도우미가 계속 페이지를 읽을 수 있습니다.
* 크롤러는 방문자가 무엇을 액세스할 수 있는지 볼 수 있습니다. 게이티드 콘텐츠가 표시되지 않습니다.
* 메타 제목, 설명 및 구조화된 데이터: Adobe Learning Manager은 학습 메타데이터를 기반으로 모든 강의, 학습 경로 및 인증에 대해 자동으로 생성합니다.

>[!NOTE]
>
>기본 Adobe Learning Manager에서 AI 및 검색 기능을 사용하려면 사용자 정의 도메인이 필요합니다. 헤드리스 배포는 설치의 일부를 자체 환경에 구현해야 합니다.

>[!NOTE]
>
>이 기능에 대한 설명서는 곧 제공될 예정입니다.

## 학습 경로에 액세스할 수 없도록 하지 않고 강의 취소

## 자체 등록 프로필에 대한 로그인하지 않은 페이지 URL

자체 등록 프로필을 사용하면 파트너 또는 여러 조직의 구성원과 같은 외부 사용자가 자신의 Adobe Learning Manager 계정을 만들 수 있습니다. 이제 각 프로필은 Experience Builder에서 빌드된 자체 공유 가능한 임시 방문 메뉴 URL을 가질 수 있습니다.

사용자가 해당 URL을 통해 도달한 페이지에서 **등록**&#x200B;을 선택하면 URL이 속한 프로필에 추가됩니다. 이렇게 하면 별도의 에이전시 또는 파트너 회사와 같은 다른 조직의 사용자가 별도의 프로필에 있게 됩니다.

## 다운로드한 보고서의 열 머리글이 변경됨

업그레이드 후에는 사용자 정의 별칭이 없는 기존 보고서가 업데이트된 머리글을 표시하지만 보고서 데이터, 필터 및 스케줄은 영향을 받지 않습니다. 스크립트, 스프레드시트, 비즈니스 인텔리전스 대시보드 또는 통합에서 머리글별로 열을 참조하는 경우 이를 새 이름으로 업데이트하거나 사용자 지정 별칭을 설정하여 특정 머리글을 유지합니다.

## 다중 Zoom 연결 지원

이제 Adobe Learning Manager은 단일 계정 내에서 여러 Zoom 연결을 지원하여 조직이 서로 다른 Zoom 계정에서 가상 강의실 세션을 관리할 수 있도록 합니다.

통합 책임자는 여러 개의 확대/축소 연결을 구성하고 이를 특정 역할이나 사용자 그룹에 할당할 수 있습니다. 강의 세션을 만들거나 편집할 때 작성자는 사용 가능한 Zoom 연결에서 선택할 수 있으며 각 세션은 하나의 연결을 사용합니다.

이러한 향상된 기능은 특히 다음과 같은 경우 여러 Zoom 계정을 사용하는 조직에 더 큰 유연성을 제공합니다.

* **부서별 교육**: 동일한 Learning Manager 계정 내에서 다른 부서나 팀에 대한 별도의 Zoom 계정을 관리합니다.
* **파트너 및 외부 교육**: 특정 파트너 또는 사용자 그룹에 전용 Zoom 연결을 할당하여 교육 세션을 지원합니다.
* **제어된 액세스**: 역할 또는 사용자 그룹을 기반으로 Zoom 연결의 가용성을 제한하여 작성자가 자신에게 할당된 연결만 선택할 수 있도록 합니다.
* **간소화된 연결 관리**: 통합 관리자가 기존 세션에 영향을 주지 않고 여러 Zoom 연결을 중앙에서 관리할 수 있도록 합니다.

## 퀴즈를 위한 안전한 시험 브라우저 통합

Adobe Learning Manager은 이제 기본 퀴즈를 위한 안전한 시험 브라우저와 통합되어 평가를 수행할 수 있는 안전하고 통제된 환경을 제공합니다. 책임자는 계정 수준에서 통합을 활성화하고 안전한 시험 브라우저 구성 파일(.seb)을 업로드하여 평가 제한을 정의할 수 있습니다. 그런 다음 작성자는 안전한 시험 브라우저가 필요한 개별 퀴즈를 선택할 수 있습니다.

학습자가 안전 검사 브라우저가 필요한 퀴즈를 시도하면 브라우저를 시작하라는 메시지가 표시됩니다. 책임자가 정의한 제한에 따라 평가 기간 동안 다른 브라우저 및 애플리케이션에 대한 액세스가 차단됩니다. 설치되어 있지 않은 학습자에게는 다운로드할 것을 요청하는 메시지가 표시됩니다.

**도움이 되는 위치:**

* **인증 평가:** 외부 리소스에 대한 액세스를 제한하는 것이 중요한 퀴즈를 수행합니다.
* **준수 교육:** 필수 교육 및 규정 요구 사항에 대한 제어된 평가를 지원합니다.
* **높은 수준의 평가:** 중요한 평가 중에 무단 응용 프로그램이나 리소스에 액세스할 수 있는 기회를 줄입니다.
* **유연한 평가 관리:** 작성자가 추가 제한이 필요한 퀴즈의 경우에만 안전한 시험 브라우저를 요구할 수 있도록 허용합니다.

[자세히 알아보기](/help/migrated/administrators/feature-summary/safe-exam-browser.md)

## 라이브 허브의 접근성 수정

Live Hub의 접근성 수정을 통해 보조 기술 및 키보드 탐색 사용자의 환경이 개선됩니다.

* **화면 판독기**: 이제 NVDA, JAWS, VoiceOver 및 TalkBack을 사용하여 컨트롤 및 콘텐츠가 올바르게 알립니다.

* **확대/축소 및 리플로우**: 콘텐츠 및 기능은 200% 브라우저 확대/축소에서 유지되며, 라이브 허브는 화면 돋보기로 작동합니다.

## Adobe Learning Manager 2026년 12월 릴리스의 API 변경 사항

### 책갈피 API 순서 지정 및 중단된 콘텐츠 처리

학습자는 나중에 다시 방문할 교육에 책갈피를 추가할 수 있습니다. 이전에는 책갈피 API에서 저장된 교육을 특정 순서 없이 반환하여 헤드리스 통합에서 가장 최근에 저장된 교육을 먼저 표시하지 못했습니다. 중단된 학습 객체의 책갈피도 목록에 남아 있어 &quot;페이지를 찾을 수 없습니다.&quot; 오류가 발생했습니다.

이 업데이트는 다음 두 가지를 모두 해결합니다.

* 이제 책갈피가 최신 항목부터 반환됩니다.
* 중단된 학습 객체에 대한 책갈피는 더 이상 반환되지 않습니다.

새 끝점, 매개 변수 또는 응답 특성이 추가되지 않으므로 기존 통합이 변경 없이 작동합니다.

[자세히 알아보기](/help/migrated/api-changes-dec-2026.md#bookmark-api-ordering-retired-content)

### 토론 게시판 강사 알림용 API

이 릴리스에는 토론 게시판 강사 알림을 지원하는 새로운 API가 포함되어 있습니다. 강사 및 코호트 관리자를 토론 게시판에 구독하고 다이제스트 전자 메일에 나타나는 활동을 제어하는 데 사용합니다.

[자세히 알아보기](/help/migrated/api-changes-dec-2026.md#api-discussion-board-instructors)

### 학습자 앱에서 다중 등록 인스턴스에 대한 API 지원

등록 API는 이제 학습자 앱에서 다중 등록 인스턴스를 지원합니다. 선택적 `includeMultiInstanceEnrollments=true` 매개 변수를 `GET /enrollments`에 추가하여 포함하십시오. 기본값은 `false`이므로 헤드리스 구현을 포함한 기존 통합은 변경되지 않고 계속 작동합니다.

[자세히 알아보기](/help/migrated/api-changes-dec-2026.md#api-multienrolled-instances-lc-widget)

### 학습 과정 등록의 마지막 액세스 날짜

이제 마지막 액세스 날짜와 같은 사용자 정의 메타데이터를 학습 경로 등록에 저장하고 API를 통해 설정하고 읽을 수 있습니다. 이렇게 하면 할당한 학습 경로에 대한 시간 바운드 액세스를 추적할 수 있습니다.

* 관리자 토큰을 사용하여 기존 등록 또는 학습자 등록 시 메타데이터를 설정합니다.
* 책임자 또는 학습자 토큰으로 읽습니다.

메타데이터는 사용자의 추적을 위한 것입니다. 액세스를 제어하지 않으며 경로의 강의에 적용되지 않습니다.

### Report Builder 내보내기의 작업 API 작업 유형

작업 API에 보고서 ID를 전달할 때 저장된 모든 Report Builder 보고서를 내보내는 새 작업 유형 `generateCustomReport`이(가) 있습니다. 새로운 L2 퀴즈 데이터 세트를 사용하면 하나의 보고서에서 여러 강의에 걸쳐 질문 수준 퀴즈 데이터를 내보내고 반복 내보내기를 자동화할 수 있습니다.

`generateQuizReport`을(를) 포함한 기존 작업 유형이 변경되지 않았습니다.

### Zoom 커넥터용 API

이러한 API를 사용하여 Adobe Learning Manager에서 Zoom 커넥터를 조회하고 관리할 수 있습니다. 기존 Zoom 연결을 검색하고, Zoom 자격 증명을 저장하고, 연결을 생성 또는 업데이트하고, 사용자 그룹 및 사용자 정의 역할에 대한 액세스 권한을 관리하는 데 사용합니다.

**API 시퀀스**

다음 순서로 API를 사용합니다.

| **단계** | **API** | **목적** | **인증** |
|------------------------------------|---------------------------------------------------------------|---------------------------------------------------------------------------------------------|-----------------------------------------------------|
| 1 | `POST /ctr/authcred/uuid/20012    ` | Zoom 자격 증명을 저장합니다. | 통합 책임자 세션 |
| 2 | `POST /ctr/app/esconnect  ` | Zoom 연결을 생성하거나 기존 연결을 업데이트합니다. | 통합 책임자 세션 |
| 3 | `PUT /ctr/xtsa/{connectionId}/access` | 연결을 사용할 수 있는 사용자 그룹 및 사용자 지정 역할을 설정합니다. | 통합 책임자 세션 |

**인증 및 권한**

이러한 API는 세션 기반 인증을 사용하며 사용자가 Adobe Learning Manager에서 통합 관리자로 로그인해야 합니다.

[자세히 알아보기](./api-changes-dec-2026.md#apis-to-create-and-manage-the-zoom-connector)
